# Interactive artwork

All artwork is original. Reference images are not shipped as product artwork.

- `jade-aperture.png` and `metal-aperture.png` are procedural Three.js prerenders,
  not downloaded models or image-generation output. Open `source.html` over HTTP
  to render the original 900x700 scene. `window.setMode('metal')` selects its
  second finish; reload returns to jade. The renderer uses the local pinned
  Three.js distribution and RoomEnvironment, whose MIT license is retained.
- Each object uses two original rounded apertures: outer 3.04x2.28 units, opening
  1.70x1.04, depth .14, bevel size .07 and thickness .065. The orthographic camera
  is at (6,6,9), with a 7.4x5.74 view. Materials, deterministic brushing, lights,
  VSM shadows, ACES mapping and sRGB output are reproducible in the source.
- `mint-matrix.svg` is an original deterministic cell field with local light
  concentration. It is displayed as a still; no runtime renderer is necessary.
- The paper, instruments, menus and controls are authored DOM/CSS.
