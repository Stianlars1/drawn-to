# Editorial showcase assets

All production images in this directory are original generated artwork. None are downloaded reference imagery.

- `garden-panorama.png`: original Aster House fixture engraving generated with OpenAI imagegen, then recomposed with imagegen for a broad landscape. Reused with authorization from the frozen warm-footer trial. Source generated file: `exec-a6db8c49-4ec8-4a63-98b1-9a9ea217e86a.png`. Original fixture remains untouched.
- `studio-bird.png`: original OpenAI imagegen scene for these showcases, 2026-09-06. Text prompt described an apricot clay bird wearing an oatmeal scarf, sketching on art books beside a plant and brushes, soft physical materials and contact shadows, pure white composition ground. No reference image input. Generated file: `exec-cadd77e0-ac51-4de2-bb97-9d57c23e3de9.png`.
- `peeking-bird.png`: second pose made through OpenAI imagegen using only `studio-bird.png` as image input. The same original character leans over a simple card edge. Generated file: `exec-80b111a6-345b-4bc3-9040-ceb455059194.png`.
- `material-studies.webp`: six original OpenAI imagegen studies, reused with authorization from the frozen kinetic-hero trial: chrome ribbon, red curtain, travertine arch, amber resin, leaves, blue glass. Source: `fieldwork-studies.webp`, 3 columns × 2 rows. Its original manifest records WebP encoding at quality 91.
- `material-details.webp`: four further original OpenAI imagegen studies from that same trial: walnut wall, folded paper, green glass, indigo textile. Source: `fieldwork-materials.webp`, 2 columns × 2 rows, quality 91 WebP.

The original source studies were visually inspected before use. Circular and arch crops are applied in CSS; the source image proportions are preserved. The production images are brand/material illustrations, not claimed client projects.

Typography uses the host catalog's existing Inter, Instrument Serif and Geist Mono loading. No additional fonts were installed or bundled.
