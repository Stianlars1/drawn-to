# GPU scene posters

These sixteen WebP files are lossless browser renders of the original live scenes
at time zero. There are desktop and portrait crops, plus Metal/Glass variants of
the material study and a Release state for the particle study. They contain no
source-reference pixels and no downloaded model.

Implementation: `site/js/graphics/three-stage.js`, `models.js`, `particles.js`.
The actual imported GLB is generated by `scripts/export-showcase-model.mjs` from
that same `foldMark` geometry. Three.js 0.185.1 is locally vendored with its MIT
license. Particles use native WGSL/WebGPU or GLSL/WebGL2, not a vgpu runtime.

For reproducible poster capture, open the page at 1440x900 or 390x844, DPR 1,
with `?v=<page-id>&still&t=0`. Wait for `#app[data-mounted="<page-id>"]` and
`[data-model-host].__stage`. For Three.js, `__stage.setTime(0)` returns PNG data;
select a material with `setMaterial(name)` first. For particles, call
`setTime(0, 1)` for Gather or `setTime(0, 0)` for Release, then await `snapshot()`.
Encode the returned canvas at its actual pixel dimensions as lossless WebP.
These are narrow QA/export hooks; visible page controls remain ordinary DOM.

The shadow under the mark/ribbon is an authored soft world-space texture; the
schedule uses actual shadow mapping. No ray-traced caustics or GPU timing claims
are made. Shader submission time exposed for QA measures CPU submission only.
