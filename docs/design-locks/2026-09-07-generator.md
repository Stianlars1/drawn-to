# Drawn To generator: approved product contract

Status: implementation authorized by the owner on 2026-09-07 after the detailed plan and independent review. English throughout.

## Product

Create `/generator`, a visual reference studio for the owner, designers/developers and nonexpert visitors. Support Start with a scene and Build from parts, with Full page, Section, Component and Graphic scopes. A page has ordered sections and explicit page defaults. The first deliverable is a copyable instruction to use the Drawn To skill/plugin and exact internal reference/property contracts. The skill performs project discovery, asks consequential unanswered questions and guides implementation. Do not substitute a standalone generated appearance brief for that workflow. No AI requests, account or backend.

## Source contract

Every selected property has a stable ID, one canonical atomic contract, exact supporting resource locators, scope and source version. Original showcase work, external inspiration, media evidence and implementation are distinct. Some scenes share inspiration; some have none. Do not assign a scene's orb reference to its unrelated typography. User choices must resolve 1:1 to the property contracts, including bounded supporting source sections.

Canonical scene contracts live under the portable skill. Existing aggregate profiles and full-scene prompts become derived views of that data; do not maintain two handwritten 70-scene descriptions. All 70 scenes get a complete audited profile and only supported properties are selectable.

The particle-orb acceptance case uses Plasma shape and color and Particle Assembly graphic construction, with layout, typography and motion left open. Explicit open masks inheritance. Reset restores it. Equivalent resolved decisions must produce equivalent handoffs regardless of entry path. Multiple competing sources can be carried as an explicit question, never silently resolved. Changes to a base preserve explicit picks. Global page defaults and section-specific choices are distinct.

## Experience

Graphite workspace, warm white text, large real showcase previews, existing Inter/Instrument Serif/Geist Mono. Sources, an inspectable source and Your direction are the central surfaces. Page structure is visible when needed. Use for shape/typography/material is explicit. Show original sources rather than falsely rendering a new combined scene. Source previews load on demand and stop/dispose when closed. Optional project context; do not repeat an agent's project interview in a mandatory form. Mobile, keyboard and touch must retain every essential operation. Motion explains source-to-choice relationships and is interruptible/reduced-motion aware.

## Persistence

Automatic separate local drafts, recoverable through a small Recent drafts menu. Shared directions never overwrite another draft. Sharing excludes every user-authored string by default, including custom labels and intent. An explicit include-context choice previews shared text. Links contain structural selections and a versioned catalog ID. Published immutable catalog snapshots retain original bindings. Unsupported versions show recovery rather than guessing. Updates create a migrated copy with a change list. Share URL product limit is 8000 characters, with portable direction JSON download/import fallback. Handle storage denial/quota and cross-tab conflicts honestly.

## Delivery

Use static HTML, CSS and small JavaScript modules in the existing repository. Keep initial generator load independent of the carousel/GPU renderers. Preserve existing routes including case-sensitive legacy aliases and scene clipboard behavior. Add Use in generator to each scene. The later Auric Orbit Pick elements pilot reuses the same source property IDs; it is a subsequent milestone, not a reason to delay a complete generator v1.
