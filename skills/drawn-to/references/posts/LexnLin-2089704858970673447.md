# Dark agency landing page for Artesiana

## What we see
Four sections of a live dark-mode landing page for Artesiana (German AI/software agency, artesiana.de): a full-width client-testimonial card, a 2+1 bento of "core fields" feature cards with vector/UI-fragment illustrations, an "Our products" section with a featured product card plus a 2-up grid, and a rounded footer container with a giant watermark logo. Everything sits on a near-black #090909 page with a faint blue-stroked blueprint grid peeking at the edges. The system is Linear-adjacent: hairline borders, skeleton-UI illustrations, one blue accent family, tightly-tracked bold grotesque headings.

## Layout & composition
- Container: ~1200-1220px centered on ~1440-1536px viewports; section vertical padding ~96-120px.
- Section header pattern: centered H2 (~52-56px, bold, tracking ≈ -0.03em, near-white #F4F4F6) + centered 16px subhead in #A4A5A7, ~16px apart, ~64px above the grid.
- Core fields: 2-column grid (cards ~592px wide) with ~28px gap, third card spans full width below — a 2+1 bento.
- Products: featured card full-width (~1216 × 460px, 2-column 40/60 text/media split), then a 2-up grid of ~592px cards, ~28px gap.
- Testimonial: single full-width card ~1216 × 480px; internal 2-column split (~26% attribution column / 74% quote) separated by a 1px vertical divider #2D3238 that runs only ~70% of card height (inset top and bottom).
- Radii: outer cards 16-20px; inner media panels 8-12px; footer container ~40px top corners; buttons 8px.
- Borders: 1px rgba(255,255,255,0.07-0.09) on all cards; the testimonial card border picks up a blue tint (#242A38) near the gradient sheen. Featured product card has a brighter top-edge highlight (gradient border, lighter at top) reading as a subtle glow.
- No drop shadows anywhere — depth comes from gradient sheens inside panels and border-brightness differences.
- Page background texture: large square blueprint grid (~70-80px cells) stroked in dim blue (#0A0E11-#10203A range), visible only at viewport edges outside the container; footer swaps it for a 3D quilted/tiled dark-glass texture with faint blue reflections.

Below: full-width hairline divider, then ~24px-padded text zone — title 18-19px semibold white (#D5D5D7 rendered), description 14px #9B9B9D, 2 lines max. Visual:text ratio ≈ 65:35.

Right: media panel radius 12px, blurred cloudy blue gradient (#12243C → #9AB6C1 highlights) with a floating mock dashboard.
- Testimonial card: brand logo top-left of the attribution column, name (15px semibold white) + role (14px #9B9B9D) bottom-left; oversized "" glyph above a 22-24px quote (~1.6 line-height, #C9C9C9-#E8E8E8); "View case study ↗" 14px semibold with hairline underline.

## Type & color
- Hierarchy: H2 ~54px/700/-0.03em → H3 ~31px/600 → card title 18px/600 → body 14-16px/400. Single grotesque family (Helvetica-Now/Inter-class) for UI; serif logotypes used only as product wordmarks for contrast.
- Palette: page #090909; card surface #101113; borders rgba(255,255,255,0.08); primary text #F4F4F6; secondary #A4A5A7; muted #9B9B9D; accent blue family — icon blue ~#4A6FC4/#3B82F6, lighter #779CED badges, skeleton highlight pills #DDEBFF; media gradients #12243C → #31424A slate blue; micro-accents: one green dot, one red dot (in wordmarks only).
- Contrast strategy: text carries almost all luminance; color is confined to media panels and pin-point accents. Backgrounds stay within a ~10-point luminance band so hairlines do the separation work.

## Graphic language
Features are shown, not told, via two devices inside the gradient media panels:
1. Vector diagram illustrations — "Agentic AI Systems" is a hub-and-spoke: central rounded-square with a 4-point blue star spark, a dashed circular orbit, four dark rounded-square satellite icons (person, graph, pause, check) on thin connector lines — literally depicting agents + human approval + logging. "Document Intelligence" is a fading dot-matrix grid feeding dark document cards with skeleton text lines, a barcode, a blue check badge, and a "99%" pill — depicting classify/validate.
2. Skeleton UI fragments — real-looking dashboard mocks with grayed skeleton bars everywhere except the load-bearing data ("Good morning", stat values 128 / 1,156 / 24h, +12% deltas, 68% ring, "24/7" gauge, extracted-contact card). Only interactive/positive elements get the blue.
Footer signature: the logo mark blown up to ~450px at ~12% gray opacity as a watermark, over the quilted texture, with the email address set at display size (~34px) above a full-width hairline.

## Why saved
No owner note. What earns the save, verified against the frames: (1) rigorous card anatomy repeated across every section — media panel + hairline divider + title/desc with the same 16px inset, so the page reads as one system; (2) features depicted through purpose-built vector diagrams and skeleton UI fragments where only the meaningful data is rendered and everything else is grayed bars — the exact "show the feature" move the owner collects; (3) editorial dark restraint: one blue family, zero shadows, depth from gradient sheens and a brighter top border on the hero card — a detail generic AI output misses; (4) texture used as background narrative (blueprint grid = engineering, quilted glass in the footer = craft) kept below ~8% contrast so it never competes; (5) serif product wordmarks with single-character color accents inside an otherwise strict grotesque system; (6) the oversized watermark-logo footer with display-size email — a confident brand close.

## Extractable rules
- Set page bg #090909 and card surfaces #101113; separate with 1px rgba(255,255,255,0.08) borders, never shadows.
- Build feature cards as: media panel (radius 8px, 65% height) + full-width hairline divider + 18px/600 title + 14px muted description.
- Fill media panels with a slate-blue vertical gradient (#152636 → #31424A) to lift illustrations off the black.
- Draw feature illustrations as diagrams of the mechanism (hub-and-spoke agents, doc pipeline), not decorative art.
- In mock UI fragments, gray-bar every element except the 3-5 data points that sell the feature; reserve blue (#3B82F6 family) for those.
- Track display headings tight: ~54px/700 with letter-spacing ≈ -0.03em, centered, with a 16px #A4A5A7 subhead.
- Give the hero/featured card a brighter top-edge gradient border to rank it above sibling cards.
- Inset internal dividers: run vertical card dividers ~70% of card height, not edge to edge.
- Put a faint blueprint grid (70-80px cells, ~5% blue strokes) only outside the content container.
- Nest radii: outer card 16-20px, inner media panel 8-12px, buttons 8px; footer container 40px.
- Close the page with the logo mark at ~450px and ~12% opacity as a footer watermark, next to a display-size contact email over a hairline.
- Use a serif wordmark with one colored terminal character to brand sub-products inside a grotesque UI system.
