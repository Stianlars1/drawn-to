# Shader-driven carousel with defocus color-morph transitions

## What we see
A single centered card carousel ("Shader Slider" by @raul_dronca) on a warm off-white page. Five slides — Clarity, Drift, Stillness, Warmth, Depth — each a grainy, slowly-flowing shader gradient (brushed-metal slate, violet smoke, forest green, amber silk, indigo dune) with a one-word title and a poetic one-liner bottom-left. Advancing a slide does not swap images: the card defocuses, the shader's palette uniforms lerp through intermediate hues to the next slide's colors, focus returns, then the new text fades in.

## Layout & composition
- Page: flat warm off-white #f7f6f2, no chrome except the component; recorded cursor included in the demo.
- Card: centered, ~57% viewport width; measured 458x290 in an 800x600 frame → aspect ≈ 1.58:1 (≈8:5, near golden ratio). Corner radius ≈ 3.2% of width (~16px at this scale, ~20-24px at production size).
- No border; elevation via a soft diffuse drop shadow plus a colored ambient bloom that tracks the shader hue (blurred copy of the shader behind the card, est. blur 80-120px, opacity 25-35% — page tint shifts #f7f6f2 → #f3f4ef around the green slide).
- Text block bottom-left inside the card: left padding ≈ 7.5% of card width (~34px here), description baseline ≈ 45px above card bottom.
- Logo mark (dotted starburst, white) top-left, same inset as text (~34px), ~22px diameter.
- Dot indicator centered ~20px below the card: 5 dots; inactive 6px circles at ~20% black; active = dark charcoal #2b2b2e pill ~24x8px, fully rounded.
- Prev/next chevrons outside the card, vertically centered at card midline, ~30px from card edges; thin 1.5px stroke, near-black #1a1a1a when enabled, ~25% opacity when disabled (left is dimmed on slide 1, right dims on slide 5).

## Card anatomy
- Visual-to-text ratio ≈ 80/20: the shader IS the card; text occupies only the bottom-left quadrant.
- Title: neo-grotesque sans, weight ~600, pure white #ffffff, ~28px at a 640px card, normal tracking.
- Description: same family, weight 400, ~15-16px, white at ~75-80% opacity, single line, sentence case with terminal period.
- One-word emotional titles + one poetic sentence, consistent across all 5 slides (Clarity / Drift / Stillness / Warmth / Depth) — the copy is a designed system, not filler.

## Type & color
- Hierarchy carried by two levels only: 600-weight title vs 400-weight 55%-size description at reduced opacity; no eyebrow, no CTA.
- Page/base: #f7f6f2. Indicator active #2b2b2e; inactive dots ~#c9c7c4.
- Slide palettes (dark anchor → bright field): Clarity #3a4149 → #a2afb8 (metallic silver-blue); Drift #2a124c → #6720c6; Stillness #126946 → #3ed890; Warmth #78390e → #ca8017; Depth #4741a3 → #3f2eb2 with silver-lavender highlight.
- Contrast strategy: white text always sits on the darkened lower-left corner of the shader (every composition places its dark mass behind the text block), so legibility survives all 5 palettes without a scrim.

## Graphic language
- One generative shader, five palettes: a diagonal S-curve silk/smoke ridge flowing lower-left → upper-right, dark vignette mass in one corner, bright specular field opposite. Reads as lit fabric/metal, not a flat mesh gradient.
- Heavy uniform film grain (~4-6% luminance noise) baked into the shader; it melts at blur peak and re-crystallizes on refocus, selling a lens "defocus" rather than a CSS blur.
- Slide identity comes purely from color + the same material: brushed steel, violet smoke, green moss-light, golden silk, indigo dune.
- The dotted starburst logo and the pill indicator are the only hard-edged graphics; everything else is continuous field.

## Motion timeline
Source: 12.48s, 2876x2160@60fps; 75 frames extracted at ~6.0fps (t = frame/6.0).
- 0.0-1.9s — idle on Clarity. Shader drifts continuously (~10px/s crest movement, linear/perlin time). Cursor travels from bottom-right to the next chevron.
- ~1.9s — click 1. t=2.0: full-card blur ramps in (est. 0→25px in ~250ms, ease-in) while text fades/blurs out and palette lerp begins. t=2.17: blur peak, text gone, indicator pill jumps/morphs to dot 2 (~200ms, at blur peak). t=2.3-2.5: blur releases (~350ms, ease-out) while hue continues slate→violet. t=2.67: title "Drift" fades in first; t=2.83: description settles ~120-150ms behind title. Full transition ≈ 850-950ms; text enters only after focus returns.
- 2.8-4.4s — idle on Drift.
- ~4.4s — click 2. Same anatomy; palette travels violet→blue→teal→green through intermediate hues (visible at t=5.0, a blue mid-state), not a crossfade. Settled with text ~5.8s.
- 5.8-7.1s — idle on Stillness.
- ~7.2s — click 3. Green→olive→amber sweep, blur peak ~7.5s, "Warmth" settled ~8.3s.
- ~8.9s — click 4. Amber blur-out ~9.16s; t=9.5: refocused but hue still muted mauve, colors keep easing ~700ms after sharpness returns; "Depth" text lands ~10.0s.
- 10.0-12.48s — idle on Depth; right chevron fades to disabled (~25% opacity); shader keeps flowing; cursor exits bottom-right, framing a clean loop.
- Easing character: blur in fast/out slow (ease-in-out overall), color lerp ≈ 900-1200ms with long ease-out tail, text fade-in ≈ 250-300ms ease-out with title→description stagger. No positional movement anywhere — everything is opacity, blur, and shader uniforms.

## Why saved
No owner note. Verified read: this is a masterclass in treating transition as material, not as layout. A generic implementation would slide or crossfade five gradient JPGs; here one persistent shader lerps its palette uniforms through believable intermediate pigments (violet passes through blue before teal), so the card feels like one physical object changing state. The craft moves a generated page would miss: the defocus pass that dissolves the film grain and re-crystallizes it; text strictly sequenced after refocus with a title→description stagger; every composition parking its dark mass under the text block so white type works across five palettes; the ambient page bloom re-tinting with each slide; and the disabled chevron states at both ends. It matches the owner's taste for motion that SHOWS the feature and for airy premium light UI with design-engineer detail.

## Extractable rules
- Persist one shader across slides and lerp palette uniforms (900-1200ms, ease-out) instead of swapping images.
- Pair color morphs with a defocus pass: blur 0→~25px in ~250ms, hold, release ~350ms ease-out.
- Sequence text out first, in last: fade out with the blur, fade in 250-300ms after refocus, description trailing the title by ~120-150ms.
- Move nothing positionally during slide changes — carry the transition with opacity, blur, and shader state only.
- Bake 4-6% film grain into the visual so blur reads as lens defocus, not CSS filter.
- Anchor each composition's dark mass behind the text block so white type survives every palette without a scrim.
- Glow the page with a blurred copy of the artwork (80-120px blur, 25-35% opacity) so ambient light tracks content.
- Keep card copy to one 600-weight word plus one 400-weight sentence at ~75% white.
- Use an 8:5 card with radius ≈ 3% of width and inner padding ≈ 7.5% of width.
- Indicate position with a 24x8px charcoal pill among 6px 20%-black dots; morph it at the transition midpoint.
- Dim, don't hide, unavailable prev/next controls to ~25% opacity at range ends.
- Let the shader idle-drift continuously (~10px/s) so the component never freezes between interactions.
