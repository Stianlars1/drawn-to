## What is visible

A dark rack combines a waveform/transport strip with distinct sound modules: sample buffer, mixer, granular controls, filter, delay, reverb, modulation, compression and tape. Each occupies its own carefully fitted tile; the graphics explain the module rather than decorating a generic card.

## Composition, material and visual weight

Almost-black surfaces, tiny warm status lights, understated dividers and consistent knobs create physical continuity. Waveform, filter spectrum, modulation curve, delay orbit and tape reels give different functional subjects a shared line language. The displayed metrics stay registered while signal data changes.

## Timeline and interaction evidence

The clip begins dark and settles into the full rack, then shows active waveform/processing changes for most of its 22.19s duration. The linked shared project currently exposes the same class of controls and clearly says changes in the shared view are not saved.

## Transferable construction

A strong adaptation can use Web Audio for actual signal flow, a real analyser for visible waveforms and keyboard-operable controls. Keep sound opt-in, preserve independent parameters and cleanly stop/dispose audio on departure. A decorative silent simulation must be labelled as such. Use density and control function, not arbitrary extra knobs, to earn the instrument aesthetic.

## Limits and risks

The recording does not establish accessibility or performance. The live project was opened read-only and its control inventory inspected; no project was saved. Do not infer that all original audio is procedural or that every displayed module maps one-to-one to a standard browser audio node.
