# SaaS hero explorations with painterly framed product UI

## What we see
Four shots of one fictional AI sales-inbox product ("Signal Sales"): three hero-layout variants of the same landing page (left-split, centered, full-bleed photographic sky) and one onboarding step (rebranded "Recline" with a serif logotype). Every variant embeds the same fully-populated 3-pane inbox UI inside a macOS window that floats on a cropped impasto oil-painting texture. The page grid itself is exposed: full-height hairline column rules with hatched/ruled gutter columns, Swiss-blueprint style.

## Layout & composition
- Outer presentation canvas: flat gray ~#D9D9D9 (photo 4 darker ~#9E9E9E); page sits as a white sheet, edge-to-edge vertically.
- Exposed scaffold: 2 vertical hairline rules (~1px, #E8E8E8) run the full page height on each side; the outer gutter column (~48px at 1x) is filled with 45° diagonal hatching (photo 1) or horizontal ruled lines at ~8px pitch (photo 2). Grid = part of the identity, not hidden.
- Content container ~1200px inside a ~1440px page; nav height ~72px with a full-width 1px bottom divider.
- Variant A (photo 1): split hero — H1 + paragraph left (~55% width), CTA pair right-aligned on the paragraph baseline. Hero block padding ~96px top, ~72px bottom.
- Variant B (photo 2): centered hero — badge chip, 2-line H1, CTA pair centered; ~24px badge→H1, ~40px H1→CTAs. Nav gains a black pill CTA at right.
- Variant C (photo 3): full-bleed azure sky photo inside a rounded device frame (radius ~24px) on gray; H1 bottom-left, supporting paragraph top-right (diagonal tension), CTAs right.
- Product window: macOS chrome, radius ~24px outer, traffic lights, frosted translucent title bar (~64px) that blurs and samples the artwork hue behind it; inner panels radius ~16px.
- Painting matte: the artwork only survives as an ~80–140px border around the window — texture as frame, never as noise behind text.
- Onboarding (photo 4): 50/50 split — zoomed app sidebar left, form right on #EFEFEF; selectable chips wrap in a row with 12px gaps; full-width dark Continue button; 4-dash progress indicator bottom-center; "Next" pill top-right.

## Type & color
- Grotesk (SF Pro Display / Inter class) throughout product + marketing; "Recline" logotype is a warm display serif — one serif word carries all the brand personality.
- H1 ~64–72px, weight 600, line-height ~1.08, tracking ~-2%, near-black #1A1A1A (white on variant C).
- Body/hero paragraph 18px/1.55 #4F4F4F; product UI 13–14px; metadata/labels 12px #9A9A9A; section label "CAMPAIGNS" ~11px uppercase +8% tracking.
- Neutrals: page #FFFFFF, sidebar #F7F7F8, hairlines #E9E9E9, ink #1A1A1A, secondary #5F5F5F.
- Brand is pure black (#111) — squircle logo, primary buttons. Color enters only as (1) semantic state: red ~#D64545 "Not Interested", green ~#2EA84F "Interested"/lead-score ring 85, yellow/green campaign status dots; (2) the artwork: cobalt #2E5BD7 + gold #D9B36A + lavender #9B8ED1 (photo 1), sunset orange #E07A3F (photo 4), azure sky #3B82F6→#7EB3F7 (photo 3).
- Contrast strategy: monochrome UI so the painting and the two state colors are the only saturation on the page.

## Graphic language
- No illustration of "features" — the feature story is told by the real product UI itself, fully art-directed: believable inbox threads, an "AI GENERATED" reply card with 1/3 version pagination and a "Generate another version" black chip, a lead-score ring (85 / High), Cmd+K search hint, unread-count badges on every nav item. Zero lorem ipsum.
- Fine-art impasto textures (Van Gogh-like skies and flower fields) used as window mattes — high-culture texture against clinical UI is the whole aesthetic bet.
- The frosted window chrome acts as a color bridge: it inherits blue over the blue painting, orange over the sunset one.
- Blueprint framing (hatched gutters, exposed column rules) signals design-engineer precision without a single word.

## Why saved
No owner note; tweet text is "Some of my favourite designs ☺️" — the author's own portfolio picks. Fits the owner's taste for airy premium light UI and UI-in-situ feature storytelling. The moves a generic AI page would miss: (1) the grid rendered as visible hairlines + hatched gutters instead of invisible padding; (2) artwork used only as a thin matte around the product window, keeping text zones pure white; (3) translucent chrome that samples the matte's hue so screenshot and frame feel physically composited; (4) one product UI reused verbatim across three hero layouts — a systematic A/B exploration, not three unrelated shots; (5) product mock dense with believable microcopy and semantic state color while marketing chrome stays strictly monochrome.

## Extractable rules
- Expose the layout grid: run 1px #E8E8E8 column rules full page height and fill outer ~48px gutters with 45° hatching or 8px-pitch ruling.
- Frame product screenshots with a textured art matte only 80–140px wide; never let texture run behind text.
- Give the app window a frosted title bar (blur ~20px, ~60% white) so it inherits the backdrop hue.
- Keep marketing chrome monochrome (#111 on #FFF); reserve saturation for semantic states (red negative, green positive) and the artwork.
- Set H1 at 64–72px/1.08, weight 600, tracking -2%; pair with 18px/1.55 body in #4F4F4F.
- Pair CTAs as black filled + white 1px-bordered ghost, both ~48px tall, radius 10–12px, chevron on the secondary.
- Populate product mockups with real microcopy, counts, and one AI moment (versioned reply, regenerate chip) — no placeholder text.
- Use radius hierarchy: window 24px, inner panels 16px, buttons 10–12px, chips pill.
- Explore heroes as a system: same nav, same screenshot, three layouts (left split, centered + badge, full-bleed image with diagonal copy placement).
- Put one serif logotype on an otherwise grotesk system when the brand needs warmth.
- Onboarding options as radio chips: pill radius, 1px border, check icon replaces the radio dot when selected, selected border darkens to #C9C9C9.
- Show progress as 4 short dashes (24px x 3px) centered at the bottom, filled dark up to the current step.
