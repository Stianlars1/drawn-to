Top-left: Droxy AI, a light feature-card grid toured by an animated camera. Top-right: Seamless.AI, a light blue hero with contact cards and a cycling mega-menu. ## Graphic language
- Droxy: features are depicted as miniature working systems - hub-spoke node maps with dotted bezier connectors, circular icon chips (28–36px, white, soft 1px ring + shadow) that pop in, real logos as trust props, a chart that draws itself. Zero stock illustration.
- Seamless.AI: photographic contact cards as the product's output, plus hand-drawn annotation doodles floating in the hero margin (arrow scribbles, tiny avatars) for warmth.
- Lightdash: the graphic IS the product screenshot, and it is alive - dropdowns open, chart types flip, toasts fire.
- Datawizz: 3D iridescent glass prism with a slow light sweep and a lens-flare sparkle; step section uses code snippets, request-log rows, and model-weight chips ("Open-weights Model | 8B") as illustrations; bento glows are blurred gradient blobs clipped by card bounds.

## Why saved
No owner note. This is a taste-profile bullseye four times over: (1) Droxy's feature cards SHOW the feature - every card visual is a live micro-animation of the actual capability, the exact "show don't describe" pattern the owner collects; (2) Datawizz is textbook editorial dark UI - Linear-grade restraint (500-weight headings, #0a0710 ground, one purple accent, glow confined to card bounds), plus scroll-highlighted manifesto text and a sticky step-storytelling section; (3) Lightdash and Seamless are the airy premium light mode: pastel gradient grounds, single accent, proof rendered as UI chips. The craft moves a generic AI page would miss: the camera tour that turns a static card grid into a narrated demo and loops back to its opening frame; charts that draw themselves inside 300px-tall cards; the mega-menu keeping its chrome fixed while only list content crossfades; scroll-scrubbed (not time-based) word highlighting; per-site discipline of exactly one accent color.

## Extractable rules
- Animate the visual inside each feature card as a live micro-demo of the feature; never use a static decorative image.
- Tour a feature grid with an auto-camera: zoom ~2×, pan 600–800 ms ease-in-out, dwell 1.5–2 s per card, end where you started for a seamless loop.
- Draw charts on entry: path reveal left→right ~700 ms, then stagger supporting data rows in at ~100 ms intervals.
- Depict integrations as hub-and-spoke node maps: 28–36px circular icon chips, dotted bezier connectors, pop-in scale 0.6→1 with slight overshoot (~250 ms).
- Keep light-mode pages to one accent hue; let third-party brand logos and green data-deltas (#22c55e) supply the rest of the color.
- Put white cards on a #f6f6f8 page with 1px #ececf0 borders and no shadow; reserve layered shadows (0 20px 50px rgba(30,40,90,.15)) for floating proof cards.
- In mega-menus, swap only list content (150 ms crossfade) while panel chrome, promo column, and footer CTA bar stay fixed.
- Render social proof as UI artifacts - verified email/phone chips, star rows, KPI numbers - not as adjectives.
- On dark editorial pages use #0a0710 ground, #141319 cards, 1px rgba(255,255,255,.06) borders, 500-weight white headings, and one violet accent (~#a78bfa).
- Scroll-scrub manifesto text word-by-word from #4a4653 to #ffffff; tint 2-3 key phrases in the accent color.
- Build process stories as sticky sections: left media panel morphs per step, right step rail with a 1px progress line and dimmed inactive steps.
- Clip gradient glows inside bento card bounds and give them only to the wide cards; keep square cards matte for rhythm.
