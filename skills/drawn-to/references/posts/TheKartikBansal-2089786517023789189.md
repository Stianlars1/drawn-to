# Profile card in matched light and dark themes

## What we see
A single social profile-card component ("Maya Chen") rendered twice on an identical cool-gray canvas — photo_1 is the light theme, photo_2 the dark theme (tweet asks "Light or Dark?"). The card is a die-cut "sticker": a thick solid outline ring (pure white in light, pure black in dark) wraps a red/orange painterly cover image, a warm-neutral body panel with name/handle/bio/location, a rounded-square avatar straddling the cover/body seam, and one full-width tonal "Say Hello!" button. The only element that does not change between modes is the cover artwork and avatar photo.

## Layout & composition
Measured on the 1700x1800 px renders (halve for a ~530 px logical component):
- Canvas: flat #e5e6eb, identical in both shots; card centered, zero drop shadow — outline ring replaces elevation entirely.
- Card: 1060 x 992 px (x 320-1380, y 404-1396), outer corner radius ~100-103 px.
- Outline ring: 24 px solid; #ffffff (light) / #000000 (dark). Same token drawn around the avatar.
- Cover band: y 430-724 inside the ring, ~294 px tall (~30% of card height), full-bleed behind the body panel.
- Body panel: overlaps the cover with its own rounded top corners ~42 px; fills the remaining inner area. Light #f2efe8 (warm cream), dark #1a1710 (warm near-black) — both warm-tinted, neither pure white nor pure black.
- Horizontal padding rhythm ≈ 45 px everywhere: text left inset 45-47, avatar right margin ~46, button side insets ~45, button-to-bottom gap ~49.
- Avatar: 205 px rounded square (radius ~66 px ≈ 32% of side — iOS-icon proportion), own 8-10 px ring in the frame color, positioned right, straddling the cover/body seam roughly 70% above / 30% below (y 578-783 vs seam 724).
- Button: 917 x 117 px, corner radius ~45 px (large-radius rect, deliberately NOT a pill; matches the body panel's ~42 px top radius).

## Card anatomy
Visual (cover + avatar) ≈ 30% of card height, text block ≈ 55%, button ≈ 15%.
- Row 1: name + handle inline, baseline-aligned ("Maya Chen" 52 px semibold, "@mayachen.design" 40 px regular warm gray).
- Row 2: 3-line bio, 40 px regular, 52 px line pitch (1.3), pipe separators "Design systems | UX | Coffee".
- Row 3: location with ~36 px stroke pin icon, 38-40 px medium, near-full-contrast color.
- Row 4: full-width tonal CTA after a large ~100 px breathing gap.

## Type & color
Grotesque sans (Inter/SF-class). Hierarchy by size + tone, not weight extremes: name 52/600; handle 40/400; bio 40/400; location 38/500; button 40/500.
- Light: body #f2efe8, name ~#0a0a0a, handle #99968d, bio #5a5957, button #e6e2d6 with near-black label.
- Dark: body #1a1710, name ~#fdfdfd, handle #8a877e, bio #aaa9a7, button #303030 with #cdcdcd label.
- Shared: canvas #e5e6eb, ring #fff/#000, cover reds #ff001e core, #ffa492 peach, orange highlights; avatar ring red edge #ff0126 where cover shows through.
Contrast strategy: the cover carries 100% of the saturation; every UI surface is a warm neutral. The button is tonal (same hue family as the body, one elevation step), never accent-colored — secondary in both modes.

## Graphic language
No illustration system — the feature IS the theming. The cover is an abstract painterly blur (red-to-orange brushstroke gradient, motion-blur softness), used unchanged in both modes; it pops harder against the black ring, softer against white. Avatar photo (green plants) is a deliberate complementary against the red cover. The sticker outline is the single graphic device: a flat solid ring standing in for shadow, card border, and avatar border simultaneously.

## Why saved
No owner note. Fits the owner's design-engineer taste as a compact theming lesson: the two frames are a token-flip demonstration, not two separate designs. The craft moves a generic AI page would miss: (1) surfaces are warm-tinted inversions — cream #f2efe8 vs #1a1710, both sharing the cover's warm undertone, instead of naive white/#121212; (2) the outline ring and avatar ring flip together as one token (white↔black), proving the border is systemic, not decorative; (3) the CTA stays tonal in both modes (#e6e2d6/black vs #303030/#cdcdcd) so the cover remains the only saturated element; (4) elevation is replaced by a die-cut outline — zero shadows, which survives mode inversion perfectly (shadows don't); (5) a single 45 px spacing token governs every inset; (6) radii step down coherently 100 → 66 → 45/42; (7) the presentation isolates the variable — identical canvas, identical content, only the theme changes.

## Extractable rules
- Tint dark-mode surfaces with the accent's undertone: cream #f2efe8 light maps to warm near-black #1a1710, never neutral #121212.
- Replace drop shadows with a 12 px (logical) solid outline ring that flips #fff to #000 with the theme.
- Reuse the frame-ring token on the avatar border so card and avatar read as one die-cut piece.
- Keep exactly one saturated element (cover art); make every button and surface a tonal neutral in both modes.
- Let a full-bleed cover occupy ~30% of card height and slide the body panel over it with ~21 px top radius.
- Straddle the avatar across the cover/body seam ~70/30, sized ~20% of card width.
- Use rounded-square avatars with radius ≈ 32% of side, echoing the card's corner language.
- Step radii down the hierarchy: card 50 → avatar 33 → button/panel 22 (logical px), never one radius everywhere.
- Give the CTA a large-radius rect (radius ≈ 38% of height), not a pill, to match panel corners.
- Drive all insets from one spacing token (~22 px logical): text padding, avatar margin, button insets.
- Build text hierarchy with size and warm-gray tone steps (#5a5957 / #99968d on cream), keeping weight between 400-600.
- Desaturate the handle to a warm gray in both modes (#99968d / #8a877e) instead of pure gray.
- When comparing theme variants, hold canvas, content, and layout pixel-identical so only tokens change.
