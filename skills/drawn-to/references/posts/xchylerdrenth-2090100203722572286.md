# Rejected Attio brand explorations, editorial dark UI

## What we see
Three boards from a rejected Attio brand/web exploration: (1) a composite with a blog-post header card, a "Universal Context" feature list card, and a "Developer Platform" hero; (2) a monochrome pattern sheet — generative line studies shown on black, white, and dark bands; (3) a full homepage hero where a sphere is drawn from horizontal dot-terminated range lines that pick up color only inside the sphere silhouette. Everything else is a strict near-black grayscale system with hairline blueprint grids and mono-type metadata.

## Layout & composition
- Canvas: boards presented on #dbdbdb–#ebebeb light gray mat, ~90–130px margin.
- Page background: #101113 (cards vary #121315–#131416). No shadows anywhere; flat planes separated only by 1px dividers at ~rgba(255,255,255,0.08).
- Containers are sharp-cornered (radius 0). Radius exists only on buttons (~6–8px) and the primary "Start for free" white button (~8px).
- Blueprint grid overlay: hairline verticals/horizontals that extend PAST content bounds and cross card edges; secondary dashed 1px inner frames around the hero content area (drafting-table register marks).
- Nav: ~64px tall, logo left, 6 text links (15px, #b6b8bb), ghost "Talk to sales" (1px border) + solid white "Start for free" right.
- Homepage feature strip: 5 equal columns with 1px full-height dividers, ~28px cell padding, mono index "→ 0.1"…"→ 0.5" top-aligned, 3-line body bottom-aligned; ~90px of dead air between index and copy.
- Universal Context card: 3 rows on a visible hairline cell grid; left edge carries a ruler rail of 1px×12px ticks at ~8px spacing with a brightened white cluster marking the active row — a scroll-scrubber metaphor.
- Blog card: texture header (~35% of card height) / meta row / title / large void / byline footer, all separated by hairline rules.

## Card anatomy
- Blog card: visual ~35%, text ~65% but mostly deliberate empty space. Meta row in 12px mono uppercase ("BLOG / PRODUCT" left, "4 MIN READ" right, +8% tracking), 44–52px regular-weight title, footer byline row with 28px avatar, name in #ededed + role in #8b8e93.
- Universal Context rows: icon cell (~140px sq) left, 2–3 line copy right. Icons are radial gauge dials — a circle of tick marks, a quarter-arc fill that advances per row (12→3→6 o'clock), dashed inner circle. Row states fade by whole-row opacity: 100% / ~60% / ~35%, implying a scroll-linked active item.
- Feature strip cells (homepage): index label top, copy bottom; first phrase white (#ededed), remainder gray (#8b8e93) at identical size/weight — emphasis by color, never bold.

## Type & color
- One grotesk (Inter/Helvetica-class) + one mono (JetBrains-Mono-class). Display set at REGULAR 400 weight: hero "Dream. Code. Ship." ~64–72px, homepage headline ~56px, tracking −1 to −2%.
- Two-tone headline device: "The only CRM with" in #9a9a9a over "Universal Context ™" in #ffffff — hierarchy inside a single headline via value, not size.
- Mono everywhere metadata appears: "[ DEVELOPER PLATFORM ]" bracket badge, "→ 0.1" indices, "BLOG / PRODUCT", "UNIVERSAL CONTEXT" — 11–12px uppercase, +8–10% tracking.
- Palette: bg #101113 / #131416; text #ededed primary, #8b8e93 secondary, #5d5e60 tertiary; dividers ~#26272a. Gray ramp in graphics: #323335 → #4a4b4d → #5d5e60 → #707070 → #a9a9a9 → #c9c9c9.
- Color appears exactly once: the sphere viz maps a spectrum around its surface — cyan #c9eef4, yellow #d6b764, olive #a3b359, green #5e9b41/#1d813b, teal #3f9c77, peach #f1b392, pink #f3b7be — desaturated to sit on dark without glowing.

## Graphic language
- Concepts are depicted with generative monochrome LINE systems, zero illustration: asymmetric starbursts and woven diagonal grids with dot-terminated line ends (network/context); a barcode gradient of vertical bars whose widths and values step geometrically from hairline #323335 to wide #a9a9a9 slabs (an easing curve made physical — reads as "ship velocity"); horizontal scanline/equalizer bars with vertical luminance gradients (blog header texture and page-footer transition strip).
- The hero sphere is a range/Gantt plot: ~30 horizontal hairlines with endpoint dots; where rows intersect the sphere silhouette, the span brightens and takes hue — structure emerges from data-plot primitives, not from a rendered 3D asset.
- The pattern sheet proves inversion discipline: every texture is shown black-on-white and white-on-dark, same geometry — the system is mode-agnostic by construction.
- Gauge-dial icons reuse the tick-ring vocabulary of the ruler rail, so icons, scrubbers, and patterns all speak one geometric dialect.

## Why saved
No owner note; tweet text is "Rejected explorations for Attio". This is precisely the owner's editorial-dark-UI lane (Linear-grade restraint) executed at brand level. The moves a generic AI page would miss: emphasis carried entirely by gray value (two-tone sentences, 100/60/35% row-opacity stagger) instead of bold weights; display type at 400 weight; radius reserved for buttons only; the blueprint grid deliberately overshooting content edges; mono type used as a consistent "systems voice" for every piece of metadata; abstract features explained by generative line mathematics (barcode easing gradient, dot-plot sphere) rather than illustration; and one single, earned moment of color on the entire page. It is also a lesson in shipping an invertible pattern system — assets designed to survive both modes. That these were REJECTED sets the owner's quality bar.

## Extractable rules
- Build dark pages on #101113; separate planes with 1px rgba(255,255,255,0.08) dividers, never shadows.
- Keep containers at radius 0; allow 6–8px radius on buttons only.
- Set display type at weight 400, 56–72px, −1 to −2% tracking; carry hierarchy with size and gray value, not boldness.
- Emphasize inside sentences by color: lead phrase #ededed, remainder #8b8e93, identical size/weight.
- Stagger list-item states by whole-row opacity 100% / 60% / 35% to imply an active scroll position.
- Voice all metadata in 11–12px uppercase mono at +8–10% tracking: "[ SECTION ]", "→ 0.1", "BLOG / PRODUCT".
- Depict abstract features with generative monochrome line systems (radial bursts, barcode width-gradients, dot-terminated line fields), not illustration.
- Permit color once per page, inside one data visualization, as a desaturated spectrum mapped over structure.
- Draw a blueprint grid whose hairlines extend past content bounds; add dashed 1px inner frames for content registers.
- Design every texture invertible: verify it on #ffffff and #0e0f11 before shipping.
- Use tick rails (1px × 12px ticks, ~8px gap) as scroll indicators with a brightened active cluster.
- Lay out feature strips as equal columns with full-height 1px dividers, mono index top, copy bottom, ~90px air between.
