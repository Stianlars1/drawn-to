## What transfers to Drawn To

- Ask about meaning and use, not only colors. Discover existing project facts
  first so the owner does not have to repeat them.
- Explain the useful relationship in each reference: layout, type, spacing,
  material, hierarchy or interaction. An observation can be useful without
  inventing an exact number.
- Let a supplied reference board widen the current library instead of forcing
  every reference into a pre-existing family.
- Separate an asset's purpose, composition, palette and output constraints
  before generating an original illustration.
- Build in coherent parts when it helps review; do not turn that suggestion
  into a prohibition on completing an already-authorized full page.
