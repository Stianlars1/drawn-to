# Five-card features bento for an AI design tool

## What we see
A "Core Features" section for a fictional AI design tool: centered header (eyebrow + 2-line H2 + subcopy) above a 5-card bento on a light gray panel — two mirrored 60/40 rows of white cards, closed by a full-width near-black card. Every card's illustration is a staged scene from the product itself (mockups, selection handles, version carousels, token sheets, multiplayer cursors), all telling one continuous story about a fake client brand "Identiq" (identity verification).

## Layout & composition
- Page bg #F9FAFC; section panel #F1F2F2 (no visible radius break at crop), panel width 1200px @1x centered with 120px side margins (1440 design width, image is @2x).
- Panel inner padding 16px on all sides; card gap 16px both axes — one consistent 16px gutter everywhere.
- Row 1: 690px + 462px cards (≈3:2 split of 1168px content width), height 557px. Row 2 mirrors it: 462px + 690px, height 556px. Row 3: single 1168 × 399px dark card. The mirrored asymmetry creates a zig-zag reading path; the equal row heights keep it calm.
- Card radius ≈14–16px; white cards with a ~1px #E2E2E2 hairline (or 1px-tight shadow) against the #F1F2F2 panel — no drop shadows at layout level.
- Header block sits on the page bg above the panel: eyebrow ~13px, H2 two lines ~48px/52px, subcopy ~16px, everything center-aligned; cards ~120px below the subcopy.
- Card text padding ≈30px sides, ≈40px top.

## Type & color
- One neo-grotesque family throughout (SF Pro / Inter class). H2 ~48px w600, tracking ≈ -0.02em; card titles ~20px w600; body 16px/1.6 w400; eyebrow 13px w600 uppercase, tracking ≈ +0.08em.
- Ink: #0A0C12 titles, #6C737D secondary — only two text grays.
- Accent system: one blue family carries everything — eyebrow #2684E6, hero gradient #76A3F4→#1E74E5, cyan ramp #27C6FE→#2696D8, selection chrome ~#1DA1F2. Green (#3ECF6A verification) and amber (warning) appear only as micro-signals inside illustrations, never at layout level.
- Contrast strategy: 4 white cards + 1 near-black finale; the dark card proves the system in both modes and works as a visual full-stop.

## Graphic language
The tool's own UI chrome is the illustration vocabulary: Figma-style selection handles, dashed marquees, version pills, named multiplayer cursors, token sheets, prompt bars. Nothing is an abstract metaphor — every feature is depicted as the product doing that feature to a consistent fictional client project (Identiq appears in cards 1, 2, 3, and 5). Construction details: skeleton-line phone mockups with "9:41" status bars; radial glow + dot-grid texture under focal objects; opacity as hierarchy (selected = full contrast, alternatives ghosted to ~15–30%); gradient masks and hard card-edge crops implying the scene continues beyond the frame; believable micro-copy density ("99,8% Biometric Match", "256-bit protection active", "Saas Website Version 8") — one human typo ("Enchance prompt") betrays the rest is hand-placed, not templated.

## Why saved
Owner note: "features bento — owner LOVES this one. Graphic/vector/illustration design-engineer choices for depicting features pictorially are 'incredibly well executed'."
Verified. What separates this from an ordinary feature grid:
1. **Diegetic illustration** — features are shown as the product operating on real content, using the product's own interaction chrome (handles, marquees, cursors) as the drawing language. A generic AI-generated page would drop in icons or stock 3D blobs; this uses zero icons at illustration scale.
2. **One narrative world** — a single invented client brand threads all five cards, so the section reads as one continuous demo session, not five clip-art slots. This is the highest-effort move here and the least imitated.
3. **Crop-and-fade composition** — content bleeding off card edges (variant carousel, swatch row) turns each card into a window onto a larger canvas, implying scrollability and scale without adding a single word.
4. **Opacity as attention** — every scene has exactly one full-contrast hero; alternates are ghosted. The eye lands correctly in all five cards.
5. **Grid discipline with a twist** — strict 16px gutter and equal row heights, but mirrored 60/40 → 40/60 rows plus an inverted dark full-width finale: rhythm, asymmetry, and an ending.
6. **Micro-copy realism** — status bars, percentages, bit-counts, version numbers. Density of plausible detail is what makes mockups-in-mockups feel like screenshots of a shipped product.

## Extractable rules
- Set the bento on an inset #F1F2F2 panel over a #F9FAFC page, with one 16px gutter for panel padding and card gaps alike.
- Split 2-card rows 60/40 (~690/462 @ 1168 content width) and mirror the split in the next row.
- Keep all cards in a row exactly equal height (~557px) and end the section with a full-width dark card (~400px) as a finale.
- Use white cards, 14–16px radius, 1px #E2E2E2 hairline, no drop shadows at layout level.
- Top-align a fixed text block per card: ~20px w600 title, 16px/1.6 #6C737D 2-line description capped at ~85% width; give the illustration the remaining ~70% of the card.
- Depict every feature as the product operating on real content — reuse the tool's own UI chrome (selection handles, dashed marquees, cursors, pills) as the illustration vocabulary; no icons at hero scale.
- Invent one fictional client brand and reuse its mockups across all cards in the section.
- Ghost every non-hero element to 15–30% opacity; allow exactly one full-contrast focal object per card.
- Crop repeatable content (variants, swatches) at card edges and fade the outermost items to imply continuation.
- Run one blue family for all accents (#2684E6 UI, #1E74E5 hero gradient, #27C6FE ramp); confine green/amber to micro-signals inside illustrations.
- Salt mockups with plausible micro-copy: "9:41" status bars, percentages, version labels, protocol details.
- Header formula: 13px uppercase blue eyebrow (+0.08em) → ~48px/1.1 w600 two-line H2 (-0.02em) → 16px gray subcopy, all centered above the panel.
