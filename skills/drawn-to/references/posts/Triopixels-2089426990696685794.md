# Periwinkle feature-card grid with per-card hover states

## What we see
A light SaaS features section ("What we Offer" / "Smart Features For Smarter Work") built as a 2x2 grid of feature cards plus one full-width analytics card below. Each card's top ~60% is a periwinkle-blue gradient "sky" with a fine grid texture that dissolves into the white text zone - no divider anywhere. The 16.4 s video (3024x1964 @ 50fps) is a camera dolly plus cursor demo: every card carries its own bespoke hover choreography (a state toggle, fanning pills, drifting avatar nodes, a bar color state), and card 4's avatar network floats ambiently the whole time.

## Layout & composition
- Centered narrow content column, ~48% of the 1512 pt viewport; at a 1200 px container read it as: 2-col grid `repeat(2, 1fr)`, gap ≈ 32-40 px both axes, plus a full-width row-3 card spanning both columns.
- Card aspect ≈ 1.6:1 (grid cards); bottom card ≈ 2.4:1.
- Corner radius is extreme: ≈ 13-15% of card width (≈ 48-64 px on a ~420 px card), continuous-corner / squircle character. This "pebble" rounding is the section's strongest silhouette signature.
- No borders, no dividers anywhere. Separation is done purely by white card surface vs. off-white page (#FBFBFC-#FFFFFF) and one soft, wide drop shadow per card: approx `0 24px 48px -12px rgba(50,70,130,0.14)` - cards read as puffy floaters.
- Section header centered: eyebrow ~12 px grey, headline ~44 px, subhead ~15 px; header→grid spacing ≈ 48 px.
- Visual-to-text: gradient zone occupies top ~60-62% of each card; text block bottom ~38%, left-aligned, padding ≈ 28-32 px.

## Card anatomy
All five cards share: gradient visual area (top) → title (~18-20 px semibold, near-black) → 2-line description (~14-15 px, grey #8A8F98, line-height 1.5). The gradient fades to pure white before the title line, so the "image" and "text" zones blend with zero seam.
1. **Smart Prioritization** - three stacked company rows ("Creativity Studio", "Luckly Company", "Speedly Co"), each a glassy translucent pill (white text on rgba-white-blue fills) with an avatar chip on the right; widths shrink downward, opacity steps ~1 / 0.7 / 0.45, each row rotated ~-4 to -7° (fanned like slats); lime status dot (#61FF6B, glowing) top-right of row 1.
2. **Custom Blueprints** - black keycap pill "Focus Mode / Disabled" (#15191A, inner top highlight + drop shadow, white 13 px label + 10 px grey sublabel) beside an overlapping avatar row (-8 px overlap), avatars desaturated, center avatar scaled ~1.5x with 3 px white ring.
3. **Seamless Team Sync** - three chat pills stacked diagonally: "Share Link" (grey #6E7273, top-left), "Team Discussion" (black, prominent, center), "Invite by Email" (ghost rgba(255,255,255,0.25), bottom-right). Depth via tone: dark = foreground, ghost = background.
4. **Intelligent Assistance** - 4-5 circular avatar nodes (44-56 px, white rings) connected by thin translucent white lines, a floating network graph over the gradient.
5. **Overview / Momentum at a Glance** (full-width) - "Overview / This Week" top-left; 11 fully-rounded bars (radius ≈ 10-12 px, equal width), all #E5ECFE except one hero bar #2349DA; horizontal dashed threshold line at the hero bar's top; floating white tooltip card pinned above it: "Focus Time · 8.4h · +24%" (green delta). Title + desc bottom-left inside the same card.

## Type & color
- Geometric sans throughout (Poppins/Gilroy character). Hierarchy: eyebrow 12 px grey → headline ~44 px medium/semibold near-black #17181A → subhead 15 px #8A8F98 → card titles 18-20 px semibold → descriptions 14-15 px #8A8F98.
- Palette: page #FBFBFC-#FFFFFF; card white #FFFFFF; periwinkle gradient #C8D6FB → #8FA5F5 (deepest corner) → white; grid lines rgba(255,255,255,0.5); accent indigo #2349DA (hover state #607DE1, muted bars #E5ECFE); ink black #15191A pills; greens: active button #1D9847, status dot #61FF6B, delta text #34B368.
- Contrast strategy: one saturated indigo element per card maximum (hero bar, or nothing); black pills carry the "UI object" weight; green is reserved exclusively for status/positive signals. Everything else stays inside the periwinkle-white envelope.

## Graphic language
Features are depicted as floating pseudo-UI fragments - pills, chips, avatars, bars - not illustrations or screenshots. Construction details: photographic circular avatars (color-graded, some greyscale until "activated"); black neumorphic keycap pills with inner highlights; glassy translucent row pills; a fine white grid texture masked to the gradient (cell ≈ 26-30 px) evoking "blueprint/canvas"; every fragment throws its own small soft shadow so the composition reads as physical layers hovering over the sky. The same gradient + grid + fragment recipe repeats across all five cards, which is what makes the set feel like one system.

## Extractable rules
- Fade the card's gradient visual to pure white before the text block; never draw a divider between visual and text zones.
- Set card radius to ~13-15% of card width (48-64 px at ~420 px) for the pebble/squircle silhouette; use continuous corners.
- Skip borders entirely; separate cards with one wide soft shadow: `0 24px 48px -12px rgba(50,70,130,0.14)` on white over #FBFBFC.
- Build the visual zone as periwinkle gradient #C8D6FB→#8FA5F5 with a masked 1 px white grid at ~28 px cells, rgba(255,255,255,0.5).
- Depict features as floating pseudo-UI fragments (pills, chips, avatars, bars), each with its own small shadow - never screenshots or stock illustration.
- Give every card a semantic hover: animate the feature's actual state change (toggle, fan, drift, highlight), not a generic lift/scale.
- Run hover transitions at 300-400 ms ease-out and reverse them symmetrically at the same duration on mouse-leave.
- Encode stack depth with tone and opacity steps (black → grey → rgba-white ghost; 1 / 0.7 / 0.45), not with size alone.
- Fan stacked pills at -4 to -8° per layer at rest; add ~3-5° more rotation plus 6-10 px spread on hover with slight spring overshoot.
- Limit saturation to one indigo element per card (#2349DA); shift it to #607DE1 as its hover/inspect state (~200 ms).
- Reserve green exclusively for status: #1D9847 active button, #61FF6B glowing dot, #34B368 positive delta.
- Keep one ambient motion layer per section (slow ±10-14 px node drift, 4-6 s period) so the page breathes between interactions.
- In bar charts, fully round all bars (~10-12 px), mute all but the hero bar (#E5ECFE vs #2349DA), and pin a tooltip + dashed threshold line to the hero.
