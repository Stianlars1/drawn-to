# Split feature cards: text half, gradient-image half

## What we see
Two standalone enterprise feature cards ("Enterprise Feature cards", 01/03 and 02/03 of a series) for a fictional recruiting SaaS "Flow Hire". Each card is a single wide panel (~1434×787 @1x, aspect 1.82:1) floating centered on a tinted page background: left half is white with an editorial text stack, right half is a full-bleed grainy gradient carrying one curated product-UI shot. Card 1 is khaki-to-orange with a cropped dashboard pinned bottom-right; card 2 is green with a floating funnel widget dead-centered.

## Layout & composition
- Canvas: 2048×1274 @1x; card occupies 70% width / 62% height, perfectly centered (equal 307px side margins, 243px top/bottom).
- Page background is a subtle vertical gradient that echoes the card's accent hue: card 1 warm ivory #F1F0EC → #E3DCD6; card 2 white #FFFFFF → pale sage #DAE4D9. Environmental color echo, not neutral gray.
- Card split: text column 53.2% / image column 46.8% (visually 50/50), hard vertical seam, no divider stroke.
- Card radius ≈ 9–10px ("small"); no border; near-invisible shadow (~2–3 RGB levels of falloff over 30px, ≈ 0 2px 40px rgba(0,0,0,0.04)) - separation is done by tone contrast against the tinted bg.
- Text column padding: 52px left, ~86px top, ~82px bottom; content measure capped at ~650px (55–60 CPL), keeping ~30px clearance before the seam.
- Vertical structure of text half: index + title pinned top; description + CTA pinned bottom; ~240px of empty air between title and description - the whitespace is the composition.

## Card anatomy
- Visual : text ≈ 47 : 53. One feature per card, one UI shot per card.
- Top block: mono index "01 / 03" (current black #000, "/ 03" muted #6B6B6B, slashed-zero mono ~22px), 20px below it the title, ~40px/500 grotesque, black, wraps to 2 lines max.
- Bottom block: 5-line description ~20px/400 #4F4F4F, line-height 41px (2.0); 49px gap; dark pill button 277×61px, fill #252525, radius ~14px, white ~20px label ("View pipeline insights" / "Analyze pipeline").
- Image half, card 1: dashboard screenshot pinned to bottom-right and cropped by the card edges; only its top-left rounded corner (~8px) is exposed, leaving an L-shaped gradient reveal ~65px wide left / ~96px top. Screenshot has its own soft drop shadow onto the gradient.
- Image half, card 2: opposite strategy - widget (~497×425 @1x, radius ~12px, soft shadow) floats exactly centered on the gradient both axes, with generous breathing room on all four sides. Same system, two crop treatments = the "unique layout vs other variants".

## Type & color
- Hierarchy: mono index (22px) → title (40px/500, tracking ≈ -0.01em) → body (20px/400, #4F4F4F) → button label (20px/500 white). Neo-grotesque sans (Helvetica Now / Neue Montreal class) + slashed-zero mono (JetBrains/Geist Mono class) for the counter.
- Text palette strictly grayscale: #000 title, #4F4F4F body, #6B6B6B muted index, #252525 button - all color lives in the image half.
- Card 1 gradient: khaki #D3CA91 (top-left) → saturated orange #F97C2C (right) → peach #FFAE62 (bottom-left); diagonal mesh feel.
- Card 2 gradient: light green #A9DD95 → mid green #7FC67A → yellow-green #D4DB8B mesh.
- Product accent inside both UI shots stays orange (~#F97316: logo, A–E letter chips) regardless of gradient hue - brand constant, ambiance variable.

## Graphic language
Features are depicted as real product-UI fragments (dashboard with treemap + KPI stats; funnel-step widget A→E with letter chips and chevrons), not abstract illustration. The gradients carry a visible stipple grain (luminance noise σ≈5 at 2x) that kills banding and adds print-like texture. UI shots are fully designed micro-products: breadcrumbs, date-range filters, +67% deltas, avatars with names - believable density, not lorem UI. Depth comes from three stacked planes: tinted page → white card → shadowed UI shot on grain.

## Why saved
Owner note: "2 images, each presenting ONE feature. Card has small border-radius, vertically split 50/50: title at top, description + CTA at bottom, right half is a large covering image relevant to the feature. Unique layout vs other variants. Liked: clean layout, lots of air giving depth and meaning, beautifully curated image."

Verified - the craft that earns it: (1) the ~240px dead-air gap between title and description+CTA is a deliberate top/bottom anchoring, not lazy spacing - it makes a marketing card read like an editorial spread; (2) page background is tinted per-card to echo the gradient hue, so each card sits in its own atmosphere; (3) two different image-crop strategies (bleed-cropped corner vs floating centered widget) inside one identical shell prove it's a system, not a template fill; (4) grain on the gradient and near-zero card shadow are restraint moves a generic AI page would replace with heavy blur shadows and flat gradients; (5) all chroma is quarantined to the image half while text stays pure grayscale - the "curated image" reads as the single color statement; (6) mono slashed-zero counter "01 / 03" signals a series and adds a technical voice against the grotesque title.

## Extractable rules
- Split feature cards ~53/47 text-left / image-right with a hard seam, no divider stroke.
- Keep card radius small (8–10px) and shadow near zero (rgba(0,0,0,0.04) 40px); separate by tone contrast on a tinted bg instead.
- Anchor title to card top and description+CTA to card bottom; leave 30–45% of card height as empty air between.
- Tint the page background (2–6% of the card's accent hue, light vertical gradient) so the card echoes its own image.
- Quarantine color: text half strictly grayscale (#000 / #4F4F4F / #6B6B6B); all chroma lives in the image half.
- Overlay stipple grain (noise σ≈4–6) on large gradients to kill banding and add texture.
- Alternate image treatment per card in a series: bleed-crop the UI to two edges exposing one rounded corner, or float it dead-centered with even margins.
- Keep one persistent product accent color inside every UI shot while the ambient gradient hue changes per card.
- Number series cards with a slashed-zero mono index ("01 / 03"), current step black, total at 40% gray.
- Type scale ≈ 22px mono index / 40px medium title / 20px regular body at 2.0 line-height, measure ≤ 60 CPL.
- CTA as dark pill: #252525 fill, ~60px tall, radius ~14px, white 20px label, sentence case, verb-led.
- Give in-card UI screenshots their own soft shadow and ~8px radius so they read as a third depth plane.
