# Feature section over cinematic photography, dark and light

## What we see
One feature section ("Relay/Respan" AI-gateway product) shipped as two identical screenshots: full dark mode and full light mode. A large two-line editorial serif headline sits above a two-column body: a numbered feature index (1.0 / 1.1 / 1.2) on the left, and tall photographic feature panels on the right with floating UI fragments composited on top - a mid-edit code window swapping `openai/gpt-4o` for `anthropic/claude-3-5-sonnet`, a provider-logo tile row, and a failover diagram (gpt-5.5 "Down" → Relay node → "Rerouting request sent…" → claude-sonnet-4 → deepseek-chat). Features are SHOWN as frozen moments of interaction, not described.

## Layout & composition
(Values at an assumed 1440px design width; screenshots are ~2.85x.)
- Full-bleed section framed by 1px hairline rules: vertical hairlines at both content edges plus horizontal dividers above/below the headline block. Dark: ~#1a1a1a on #000; light: ~#ebebeb on #fff.
- Decorative texture strip (~110px) above the headline: dark = random dithered pixel/square field (2–3px squares, gray values #2a2a2a–#9a9a9a, density fading downward); light = graph-paper grid (~20px cells, 1px #ececec lines, fading out at bottom). Same slot, different texture per theme.
- Headline block: ~64px top/bottom padding, left-aligned, max-width ~75%.
- Body: 2 columns - index column ~320px wide starting at container left edge; media column ~830px, column gap ~100px. Index top-aligns with the first media panel.
- Media panels: ~830×430px (≈1.94:1), border-radius ~16px, no border, no shadow - the photo itself is the container.
- Panel → caption gap ~28px; caption block → next panel ~120px of pure breathing room.
- Failover diagram: chips vertically stacked on a centered 1px dashed connector (dash ~4/4, white 40% in dark, white 90% over dark photo areas in light).

- Caption row: left = title + 2-line description (max-width ~55ch); right = CTA "Book a free call" aligned to panel's right edge - a white pill (dark mode) / black pill (light mode), ~52px tall, radius ~14px, containing a nested rounded-square icon with a 3×3 dot-grid (dial-pad = "call") in inverted colors.
- Code window fragment: centered in panel, ~465px wide, radius ~14px, traffic-light dots (monochrome gray in dark, colored in light) + 1px divider below them. Dark: smoked glass (black ~60% + backdrop blur over the sunset). Light: opaque white with soft shadow.

## Type & color
- Headline: high-contrast editorial serif (Tiempos/PP Editorial Old class), ~66px, regular weight, line-height ~1.15, tight tracking. Two-tone: line 1 full-contrast (#ffffff dark / #0b0b0b light), line 2 muted (#898989 / #808080) - hierarchy via color, not size.
- Index: numerals in monospace ("1.0") ~15px paired with sans labels ~18px; active row full contrast + chevron, inactive rows ~45% opacity. Mono-numbers + sans-labels pairing is the spec-sheet signature.
- Caption title: sans (SF/Inter class) ~24px, weight 500–600. Description ~18px, line-height ~1.55, #8a8a8a dark / #949494 light.
- Palettes: pure #000000 and #ffffff page grounds; ALL chroma is delegated to photography - warm amber dune sunset in dark mode, green alpine valley with pink lupines in light mode. Photo mood is matched to theme (dusk = dark, daylight = light).
- Accents: syntax colors (const #b57edc, fetch #4a9eff, strings #a3d977), Down badge #f2555a on #3a1d1e (dark) / #e5484d on #ffdae2 (light), success check white-on-circle.

## Graphic language
Features are depicted as frozen micro-interactions composited on landscape photography:
1. "One API": a code window caught mid-edit - the old model string is selection-highlighted with an I-beam cursor drawn in, and a dark tooltip chip shows the replacement string. The copy's claim ("swap by changing one string") is literally staged in the pixels.
2. "Failover": a node graph built from real UI chips - provider status badge, dashed routing line, gateway logo tile, live status toast, dismissed vs. confirmed model chips (x-circle vs. check affordances).
Photography does emotional lifting; UI fragments do explanatory lifting; glass treatment (backdrop-blur chips in dark, solid white chips in light) binds them. No abstract illustration anywhere.

## Extractable rules
- Split a two-line headline by color, not size: line 1 #fff/#0b0b0b, line 2 ~#858585, same ~66px serif.
- Number feature nav as spec items: mono "1.0/1.1/1.2" ~15px + sans label ~18px; inactive rows at 45% opacity with chevron.
- Keep feature panels text-free: ~830×430 photo at radius 16, title 24px/500 + desc 18px #8a8a8a placed below the panel.
- Demonstrate the claim inside the UI fragment: stage cursor, selection highlight, and tooltip mid-action rather than showing a static screenshot.
- Match photography mood to theme: dusk/amber imagery for dark mode, daylight/green for light mode - never recolor one asset.
- Re-derive component material per theme: dark = black 45–60% + backdrop-blur glass over photo; light = solid white + soft ambient shadow, borders ~0.
- Give each theme its own decorative texture in the same slot: dithered 2–3px pixel field on #000, 20px graph-paper grid (#ececec 1px) on #fff.
- Frame sections with 1px hairlines (#1a1a1a dark / #ebebeb light) instead of cards or background shifts.
- Build chips as chip-in-chip: 46px outer (radius 14) containing a 34px icon tile (radius 10) with its own surface.
- Fade repeated logo rows toward both edges (opacity 1.0 → 0.35) to imply an infinite marquee in a static layout.
- Connect diagram nodes with 1px dashed lines (dash 4/4, ~40% white) and let status pills overlap node corners for depth.
- Reserve all chroma for imagery and semantic badges; keep page grounds at pure #000/#fff and text on a gray ramp.
