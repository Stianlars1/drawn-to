# Three feature cards, each a looping product-story animation

## What we see
A row of three equal feature cards on a warm off-white page (Framer build, 1920x1080 capture), pitched as "Feature cards micro animations." Each card is ~70% animated visual area, ~30% text strip: "Visual Pipelines" (auto-playing kanban drag-and-drop over a sage-green blurred photo), "One-Click Handoff" (three file chips collapsing into a green .zip pill on a taupe gradient), "Crystal Clear Feedback" (object-detection-style annotations popping over playing B/W architecture footage). A chrome liquid-metal sculpture rotates continuously in the top-right corner, and every card is framed by dashed gold crop-mark borders with solid gold corner squares — a "selected element on a design canvas" motif.

## Layout & composition
- Canvas 1920x1080; content row spans x=58–1850 (~93% width), vertically centered slightly above middle (cards y≈266–806).
- 3-column grid: each card 578px wide, gap 34px (≈1.75rem at this scale), i.e. card:gap ratio ~17:1 — tight gutters, generous outer margins (~58px left, ~70px right).
- Card total ≈578x532 (aspect ~1.09:1). Visual area ≈375px tall (70%), text strip ≈145px (28%), separated by a hard edge, no divider line.
- Decorative frame: 1px dashed hairline (#c9b98f-ish) drawn ~2px outside the card, dashes extending past the corners like registration/crop marks; solid gold squares ~7px (#937d46) at each corner. One stray gold square floats on the right screen edge (y≈815 in 1920-space) implying an off-screen canvas.
- Radii: outer cards near-square (≤6px); inner media rect in card 3 ~16px; kanban columns and task cards ~10px; file chips ~12px; zip pill rounded-rect ~10px.
- Shadows: essentially none on the cards themselves — depth comes from the inner UI fragments (soft 0 4px 12px rgba(0,0,0,0.08) on kanban cards/chips).
- Background: neutral #f7f7f7 page with a large warm sand gradient wash (#e2cca4 → transparent) rising from bottom-left and pooling behind/under the cards; wash intensity subtly shifts during the loop.

## Card anatomy

- Text strip is a translucent cream overlay, so it inherits a tint from each card's visual (card 1 strip reads sage-tinted #dadbd4, cards 2–3 read warm cream #f4f2e8) — each card's neutral has "its own twist" while staying one family.
- Card 1 "Visual Pipelines": 3 kanban columns (Not started 3 / In processing 3 / Completed 2) as white 10px-radius stacks floating over a grainy, motion-blurred sage street photo. Task cards carry category tags (Security = red-on-#ffe6d7, Communication = orange-on-cream, Knowledge/Data = green/khaki pills) plus tiny avatar chips; column headers are status pills with dot + count.
- Card 2 "One-Click Handoff": vertical taupe gradient backdrop (#e1c49b edges, #fcf9f5 hot core — looks like a blurred close-up photo). Row of three white file chips with tinted icon squares: brand.fig (Figma glyph), assets.zip (tan archive icon), copy.doc (green doc icon); small olive down-arrow beneath; olive-green pill (#969a59) "client-delivery-v3.zip" with download icon.

Detection-style overlays: green corner-bracket target mid-frame, green box + "Rust" label (#207741), red box + "Damaged Floor" label (#c0392b-ish with light text) — annotations literally demonstrate "annotate directly on videos."

## Type & color
- Neo-grotesque sans throughout (Helvetica Now / Suisse character). Card titles ~26px semibold, near-black #14140f, tight tracking. Descriptions ~17px regular, warm gray ~#70746a, line-height ~1.5, exactly 2 lines each. UI-fragment micro type 11–13px.
- Palette: page #f7f7f7; sand wash #e2cca4; card neutrals — sage #a8ad8f family (card 1), taupe #e1c49b (card 2), tan #dfc39f (card 3); accent olive-gold #937d46 (markers) and #969a59 (zip pill); functional colors only inside UI fragments (tag red/orange/green, annotation green #207741 and signal red).
- Contrast strategy: everything desaturated warm-neutral except tiny saturated payloads (status tags, annotation labels, green confirm strokes) — the saturated bits are the information.

## Graphic language
- Features are depicted as miniature working product UI, not icons: a real kanban, a real file-bundling flow, a real video-annotation overlay. Every visual is a one-to-one enactment of its headline.
- UI fragments float over photographic backdrops (grainy blurred street photo, blurred close-up, architectural footage) — photography supplies texture/grain so the flat UI never sits on dead color.
- Blueprint/canvas paratext (dashed crop marks + gold corner handles) frames the whole set as "design work in progress," matching the Framer/creative-tool audience.
- One 3D element only: the rotating chrome ribbon sculpture top-right, cropped by the frame edge — adds material contrast (specular metal vs matte paper) without competing with the cards.

## Motion timeline
Source 60fps, 11.6s seamless loop; 69 sampled frames at ~5.95fps (Δt≈0.168s). Three independent loops of different periods run concurrently, so the row never reads as synchronized/mechanical.
- t=0.0 — all three cards already live (no entrance choreography; pure loop). Chrome sculpture rotating continuously, ~full revolution over ~11.6s, constant angular velocity.
- Card 2, ~3.3s loop: t≈0.3–0.7s chips fade+rise in, staggered left→right ~100ms apart, each ~300ms ease-out; hold ~1.2s while a small down-arrow pulses; t≈2.2–2.6s chips converge and compress into the zip pill (motion-blurred, ~450ms, ease-in then snap — a "suction" easing); pill solo ~1.0s; repeat (cycles land at ~t3.7, ~t7.0, ~t10.8).
- Card 1, continuous with ~2s beats: a task card lifts with slight tilt and drags to the next column (~600ms, ease-in-out); on drop (t≈2.5s) it flashes a 1.5px green outline ~400ms; at t≈3.7s the "Completed" column header swells into a "✓ Completed" green pill ~500ms then settles; column counts tick; remaining cards reflow with soft spring (~1 overshoot). The whole board also drifts laterally a few px and the photo background pans slowly — nothing is ever fully static.
- Card 3, synced to footage cuts: t=0–1.5s wide staircase shot, both labels visible; t≈1.5s cut to blurred close-up pan, labels hidden; t≈2.1s cut back to wide; t≈2.4s "Damaged Floor" (red) pops in ~200ms scale-in; t≈3.3s "Rust" (green) pops in; labels + boxes hold and micro-track the surfaces; t≈7.4s brighter zoom shot, labels out; t≈8.2s only the green corner-bracket target remains centered; t≈9.1s both labels return; loops cleanly at 11.6s.
- Easing character overall: ease-out entrances (250–350ms), ease-in "absorption" exits, one restrained spring on kanban reflow; no bounce anywhere else. Everything loops at its own period — the composition stays alive without any moment where all three cards fire at once.

## Why saved
Owner note: "Row of 3 feature cards, each with unique cool design from borders + inner layouts; good spacing/air; carefully curated colors. MAIN reason saved: each card has a large animation focal area (animation takes most of the card), a pretty neutral background each with its own twist, and a representative motion sequence highly relevant to what the feature title/description says. Liked: precision and detail in layout, style, tone."
Verified, and the note undersells three craft moves. (1) Semantic motion: each animation is a literal enactment of its copy — the kanban card gets a green confirm ring exactly when the description says "drag-and-drop," the chips compress into a named file "client-delivery-v3.zip" (versioned filename — a realism detail generic AI output never writes), the annotation labels name plausible defects ("Rust," "Damaged Floor") on footage that actually cuts and the labels respect the cuts. (2) Desynchronized loops: ~2s, ~3.3s, and footage-driven periods running in parallel, so the row feels ambient rather than choreographed — the single biggest reason it reads expensive. (3) Neutral discipline with one family, three temperatures: sage / taupe / tan visuals unified by a translucent cream text strip that tints per card, with all saturation quarantined inside the UI fragments. The dashed-gold crop-mark frames and the off-screen stray handle add a self-aware "canvas" layer that flatters the design-tool audience without touching the cards themselves.

## Extractable rules
- Give feature cards a 70/30 visual-to-text split; keep the text zone to title + exactly 2 description lines.
- Make each card's animation a literal demo of its headline verb — no abstract motion.
- Run each card's loop at a different period (e.g. 2s / 3.3s / footage-synced) so the row never fires in sync.
- Build card backgrounds from one neutral family at three temperatures (sage/taupe/tan) over #f7f7f7.
- Quarantine saturation: neutrals everywhere, full-chroma only on status tags, labels, and confirm states.
- Use blurred/grainy photography under flat UI fragments so large color fields never sit flat.
- Frame cards with 1px dashed hairlines whose dashes overshoot the corners, plus ~7px solid corner squares (#937d46) for a canvas-selection motif.
- Confirm drop/complete actions with a ~400ms green outline flash, not a modal or checkmark toast.
- Stagger sibling chips in left→right at ~100ms with 300ms ease-out fade+rise; exit by converging into the target with ease-in "suction" (~450ms).
- Tint the text strip with a translucent cream overlay so it inherits each card's hue while staying one system.
- Use realistic data in UI fragments (versioned filenames, plausible task titles, real counts) — fidelity of content is part of the visual style.
- Keep card chrome shadowless; reserve soft shadows (0 4px 12px rgba(0,0,0,0.08)) for floating inner elements.
- Add one specular 3D object at a frame edge, cropped, rotating linearly, as material counterpoint to matte surfaces.
