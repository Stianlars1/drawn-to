# Candidate review card, dark and light themes

## What we see
Two static shots of the same "candidate feedback" card component from a recruiting dashboard, rendered twice: once in a wine-tinted dark theme, once in a neutral light theme. Each shot stacks two card instances (Jack Novak / "Strong hire" in mint, Luis Martinez / "Consider" in amber) showing the status-badge system across both semantic states. Card anatomy: avatar + name + status pill header, a quoted 3-line-clamped feedback excerpt with a large hanging quotation glyph, and a two-tone action tray footer (Show profile pill, checkmark button, overflow menu). Tweet text: "components from the recent dashboard".

## Layout & composition
- Card: 784×511 px as shot (≈392×256 @1x, assuming 2x export); vertical stack of two cards with 48 px (24) gap.
- Corner radius: ~36 px (≈18–20 @1x) on the card; action buttons ~40 px radius rounded-rects (≈20), text pill and status badges fully rounded.
- Consistent 40 px (20) padding ring: avatar left inset 39 px, badge right inset 40 px, header top inset 39 px, footer buttons inset 39 px both sides.
- Two-tone split: content area 355 px tall (#251017 dark / #fafafa light) over a 154 px action tray (#0f0408 dark / #f4f4f4 light). Dark mode separates the zones by tone shift alone (no line); light mode adds a 1 px #e2e2e2 hairline on top of the tone shift.
- Internal 2-column grid: a ~66 px icon gutter (avatar, then quote glyph directly below it) plus a content column - name and body text share the exact same left axis (x=540 in shot), so every text block hangs on one vertical line.
- Footer buttons: Show profile pill 310×120 px, then 14 px gap, check button 104×120, overflow button pushed right via space-between (105×120). Button height ≈120 px (≈60 @1x) - deliberately generous touch targets, ~17 px top/bottom breathing room inside the tray.

## Card anatomy
- Ratio: ~70% content (identity + quote) / 30% action tray. Zero decorative area - the "visual" is the component system itself.
- Header row: 66 px avatar (≈33), 27 px gap, name, status pill flush right.
- Body: oversized double-quote glyph (~44 px, serif-style) sits in the icon gutter as hanging punctuation; feedback text is a 3-line clamp ending in an ellipsis ("...of edge...").
- Footer: primary text pill + two icon-only secondaries; the check and dots buttons are equal 104-px squares-ish, keeping the tray rhythm.

## Type & color
Type (grotesk, Inter-like): name ≈20 px/600; body ≈18 px/400, line-height 52 px @2x → ~1.44, slightly negative-to-normal tracking; badge and button labels ≈16–17 px/500.
Dark theme - the standout: neutrals are hue-tinted toward the brand red, not gray. Surface ramp #0f0408 (tray) → #251017 (card) → #371923 (raised button fill); ghost-button border ~#3a2028; primary text #f4e8ec and button label #f5e4ea (pink-tinted whites), secondary text #c4b7bc (pink-tinted gray); accent red quote glyph #d2303e. Status: mint text #2ad4ac on #202928 fill with desaturated #2a403a 1 px border; amber #f5b93e on #372413 with #503626 border.
Light theme - fully neutral, slightly cool: card #fafafa, tray #f4f4f4, divider #e2e2e2, button border #d9d9d9 on #ffffff fills, tonal button fill #eeeef0, primary text #0a0a0c, secondary #606065, quote glyph demoted to #98989e. Status: green #059871 on ~#eafaf4 with #cee9e0 border; amber #d37404 on #fff6ed with #ebe5d7 border.
Contrast strategy: status hues keep identity across modes but flip luminance (bright-on-dark-tint vs dark-on-pale-tint); body text sits ~2 steps below primary in both modes.

Avatars are real photos in plain circles; icons are 1.5–2 px stroke glyphs (#d6cccf dark / #57575e light).

## Why saved
No owner note. Verified reasons this earns a save for this taste profile:
1. Tinted dark neutrals - the entire dark surface ramp (#0f0408/#251017/#371923) and even the "white" text (#f4e8ec) carry the red-wine hue of the accent. A generic AI page ships gray-900; this is a themed neutral scale, the Linear-grade move.
2. Per-mode accent demotion - the quote glyph is loud red #d2303e in dark mode but neutral gray #98989e in light mode. The accent exists only where the surface can absorb it; light mode stays airy-premium instead of getting a red splotch.
3. Dual-token status system - same hue, flipped luminance, three tokens per state (text/fill/border), with the border deliberately desaturated in dark mode so the pill outline doesn't glow.
4. Secondary-button treatment swaps per mode: dark uses an outlined ghost (transparent on the darker tray, 1 px #3a2028 border) while light uses a borderless tonal fill #eeeef0 - each mode picks whichever reads one step quieter than the white/raised primary.
5. Divider logic differs per mode: tone shift alone in dark, tone shift + 1 px #e2e2e2 hairline in light - because the light tonal step (#fafafa→#f4f4f4) is too subtle to carry the seam by itself.
6. One text axis: avatar, quote glyph in a gutter; name and body flush on a single left edge - hanging-punctuation editorial typography inside a dashboard card.

## Extractable rules
- Tint dark-mode neutrals toward the accent hue: build the surface ramp (#0f0408 → #251017 → #371923 pattern) and text whites (#f4e8ec) from the brand color, never pure gray.
- Split cards into content + action tray with a tonal step (~+6% lightness dark, -2% light); add a 1 px hairline divider only in light mode.
- Give status badges three tokens per state: text, tinted fill, 1 px border; keep hue constant across modes and flip luminance (e.g. #2ad4ac/#202928/#2a403a dark → #059871/#eafaf4/#cee9e0 light).
- Desaturate badge borders in dark mode so pills read etched, not glowing.
- Demote decorative accents in light mode: what is brand-red on dark (#d2303e) becomes neutral gray (#98989e) on light.
- Swap secondary-button style per mode: outlined ghost on dark trays, borderless tonal fill (#eeeef0) on light trays; primary stays a filled pill (raised tint dark / bordered white light).
- Keep one padding ring (20) on all four card sides and align every inset element to it.
- Run all text on a single left axis; put avatars and oversized quote glyphs in a fixed ~33-wide icon gutter (hanging punctuation).
- Clamp quoted content to 3 lines with ellipsis; line-height ≈1.45 at 18px body.
- Use card radius ~20, icon-button radius ~20 at 60 height, full pills for text buttons and badges; avatar 32.
- Group adjacent actions with an 8px gap; push the overflow menu to the far edge with space-between.
- Present component shots twice - dark and light - on a plain white canvas; the theme pair is the deliverable.
