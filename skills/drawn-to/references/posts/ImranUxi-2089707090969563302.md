# Interactive UI-detail teaching demos (interfaces.dev)

## What we see
A 25.8s screen capture (2560x1440 @30fps) of interfaces.dev — a dark-mode carousel of nine self-contained interactive demo cards, each teaching one UI craft detail by letting you manipulate it live: text-wrap balance, concentric nested radii, tabular-nums counters, copy-button icon swaps, border-vs-shadow on dark, font smoothing, optical padding, keyframe-vs-transition rotation, and staged page-entrance choreography. Every demo pairs an anti-pattern (gray X-circle marker) with the correct version (blue check-circle marker) side by side. The narrator advances with circular prev/next chevrons below the stage and operates each demo's controls (sliders, checkboxes, segmented tabs, play buttons).

- Internal structure per card: full-bleed demo stage + bottom control bar separated by a 1px hairline divider (~#242424). Some demos add a top strip for marker icons or mode toggles, also 1px-divided.
- Two-column comparison demos split the stage with a single 1px vertical hairline at 50%.
- Controls row (demo 1): "Width" label left, live monospace value ("226px") right-aligned in gray, 4px-tall slider track with white fill and ~14px round thumb, "Hide guides" pill button (1px border, radius-full) at far right after a 1px vertical divider.
- Nav: two 28px circular chevron buttons (#1C1C1C bg, ~#2A2A2A border) centered 24px below the card.
- Text-measure guides in demo 1: 1px vertical hairlines ~#232323 marking each column's measure; toggleable.

## Card anatomy
- Ratio: ~80% interactive stage / ~20% control bar. Zero descriptive copy on most cards — the demo IS the explanation; only the font-smoothing card uses title+body text (17–18px semibold white title, 14–15px #8A8A8A body, line-height ~1.5).
- Verdict grammar repeated on every card: gray X-in-circle = anti-pattern, #2F9BF6 check-in-circle = correct. Markers sit either above the variant or in a top strip; technique names ("wrap", "balance + pretty", "CSS keyframe", "CSS transition") set in ~12px monospace inside 1px-bordered dark pills.
- Value annotations: black pills with white monospace text ("12px", "padding: 8px"); derived values rendered in accent blue with blue outline ("20px" = 12px inner + 8px padding), visually distinguishing input tokens from computed ones.
- Padding visualization: translucent cyan overlay (~rgba(34,211,238,0.35)) plus cyan-outlined "24px"/"20px" mono pills.

## Type & color
- UI text: geometric sans (Inter-like). Demo headline text ~17px/600 #F5F5F5; body ~14px/400 #8A8A8A; control labels 13px/500 #E8E8E8; all values and technique labels in ~12px monospace.
- Palette: bg #101010, card #171717, borders #242424, divider #232323, text-primary #F5F5F5, text-secondary #8A8A8A, accent blue #2F9BF6 (checks, checkboxes), demo-object blue #3B82F6 (app icons), cyan #22D3EE (measurement overlays), pure white for primary pill button and slider fill.
- Contrast strategy: near-monochrome dark UI where the only saturated color is semantic — blue means "correct/selected/measured". White is reserved for the primary action and live data.
- The counter demo confirms tabular-nums teaching: left pill sets "1011" with collapsing proportional 1s (narrower pill, width jitters), right pill sets evenly spaced digits at stable width.

## Graphic language
No illustration at all — every concept is depicted with real, functioning UI fragments: actual reflowing text, actual nested rounded rectangles, live counters, a real copy button, a real hero section. Abstract objects are minimal primitives (blue rounded square standing in for an app icon, with a white dot as rotation tracker). Measurement is the decorative layer: hairline guides, value pills, and translucent overlays borrowed from design-tool vocabulary (Figma-style padding highlights). The teaching mechanic is always A/B juxtaposition plus a user-operated control that stresses the difference.

## Extractable rules
- Teach or demo a feature with a working A/B comparison plus one user-operated control; never with descriptive copy alone.
- Mark anti-pattern vs correct with a fixed grammar: gray X-in-circle and accent-blue check-in-circle, identical on every card.
- On dark UI, elevate cards with a 1px ~#242424 border and no shadow; verify by flipping the background light.
- Make nested radii concentric: outer-radius = inner-radius + padding (12 + 8 = 20).
- Set animated or updating numbers in font-variant-numeric: tabular-nums to kill width jitter.
- Balance display text with text-wrap: balance (+ pretty for body) instead of accepting ragged wraps.
- Trim trailing padding ~4px (24 → 20px) on buttons whose last element is an icon; optical, not geometric, centering.
- Prefer CSS transitions over keyframes for anything a user can interrupt mid-flight.
- Stagger page entrances by group at ~150ms (or per word at ~100–120ms), each element blur(12px)→0 + fade + 8px rise over 400–500ms ease-out.
- Render live values in ~12px monospace pills; set computed/derived values in accent blue to separate them from authored inputs.
- Dim non-active carousel slides to ~35% opacity and slide ~450ms ease-out with no overshoot.
- Reserve saturated color for semantics only (selected, correct, measured); keep everything else within a #101010–#F5F5F5 gray ramp.
