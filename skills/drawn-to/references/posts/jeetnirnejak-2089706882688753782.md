# Interactive camera-aperture dial component

## What we see
A single light-mode card ("Aperture") containing a photorealistic-but-flat camera lens dial: a rotatable f-stop ring around an 8-blade iris that physically opens and closes, an EV meter scale below (-3…+3), and a readout row (APERTURE f/x, SHUTTER and ISO with ± steppers). An "Auto" pill in the header solves the exposure by spinning the ring itself. The video is a 55 s screen capture: a scripted intro choreography (closed f/16 → bloom to f/1.4 → overexposed beat → Auto solves), then live drag, stepper, and Auto interactions.

## Layout & composition
- Page: near-white #fafafa; component centered, ~427px wide at 1x (2x capture, 1924×1518 @ 60fps).
- Two-layer card: outer shell #f1f1f2, radius ~28px, no border, very soft ambient shadow; inner white panel #ffffff, radius ~20px, inset ~10px, holding dial + meter + readouts. Footer hint text sits on the exposed outer-shell strip below the inner panel (~36px tall) — a "chin" like a device bezel.
- Header row (~48px): title left, mono chip "Scene · EV 12" beside it (#ececee pill, radius full), black Auto pill right (#1a1a1c, height ~22px, radius full).
- Dial: ~230px diameter, centered, ~24px top margin inside white panel; 4px white rim ring + drop shadow rgba(0,0,0,0.18) 0 14px 28px separating it from the panel.
- Meter: full-width row ~40px under dial; 7 major ticks (1px, #d8d8da, ~14px tall) at stop intervals, mono labels below.
- Dashed 1px divider (#e3e3e5, ~4px dash) between meter and readout row.
- Readout row: 3 columns left-aligned (Aperture ~35% width, Shutter, ISO), ~64px tall, ~24px side padding.

## Card anatomy
Visual area (dial + meter) ≈ 70% of card height; controls ≈ 20%; header + footer ≈ 10%. The dial is both the illustration and the primary control — there is no separate "hero graphic"; the component demonstrates itself. Readout values are the state mirror of the dial; the ring has no steppers (direct manipulation only), while shutter/ISO are stepper-only (discrete stops) — control affordance matches the physical camera metaphor.

## Type & color
- Sans (Inter-like) only for: title "Aperture" ~17px/600 #17171a, "Auto" 13px white, footer hint 13px #8f8f96.
- Everything numeric is monospace with slashed zeros (JetBrains-Mono-like): chip "EV 12", ring f-numbers, meter labels (11px #8e8e94), readout values ~20–22px #17171a.
- Column labels: 11px caps, +0.08em tracking, #9a9aa0.
- Palette: neutral gray ramp (#fafafa / #f1f1f2 / #ececee / #d8d8da / #8e8e94 / #17171a) + near-black dial (#1e1e21 barrel, #29292c lens, blade strokes ~#77777c @ 50%) + exactly one accent: orange #f2760f (fixed index tick, active f-number, meter needle, Auto-active dot) + peach target zone rgba(242,118,15,0.16) rounded-rect fixed at meter 0.
- Contrast strategy: the dark dial is the only large dark mass on a light card, making the orange accent read at a glance; disabled stepper glyphs drop to ~#c2c2c6.

## Graphic language
Flat-vector skeuomorphism: a real lens barrel rebuilt from concentric circles — white rim, radial-gradient barrel, engraved-style rotated tick marks, f-numbers set tangentially around the ring (rotating with it), and an iris of 8 blades drawn as thin 1.5px light strokes whose intersection polygon opens/closes continuously with the f-value. Craft detail: the aperture hole's fill encodes exposure — dark gray when stopped down/underexposed, mid-gray near correct, blown-out white when overexposed — so the "photo" is the hole itself. The value indicator is inverted from a normal knob: the ring carries the numbers and rotates under a fixed orange index at 12 o'clock, exactly like a physical aperture ring against a lens index mark.

## Motion timeline
Scripted intro (self-running demo; any touch cancels):
- 0.0–0.4 s — rest state: f/16, iris a pinhole, meter needle at -3.
- 0.4–2.4 s — "bloom": ring rotates continuously f/16 → f/1.4 (~2.0 s, ease-in-out; slow start, fastest mid-span f/8→f/2.8, gentle landing). Iris blades open in sync, hole fill brightens dark→white, meter sweeps -3 → +3, readout counts through live fractional values (f/13, f/8, f/2.8, f/1.7…).
- 2.4–3.3 s — holds overexposed at f/1.4, meter pinned +3 (~900 ms dramatic beat).
- 3.3–4.0 s — Auto engages itself: orange dot lights in Auto pill, ring counter-rotates f/1.4 → f/5.6 in ~700 ms ease-out, needle glides into the peach zone at 0.

Live interaction (t ≈ 5.5 s on):
- 6.3–7.9 s — grab cursor on ring; drag gives continuous fractional stops (f/9.7 shown mid-drag) to f/11; Auto dot extinguishes on first touch; meter tracks 1:1, no smoothing lag.
- 8.7–9.9 s — shutter stepper clicks 1/250 → 1/60; each click shifts meter exactly one stop.
- 11.5–15.8 s — long drag f/8 → f/4 → f/1.4; then shutter stepped down to 1/8 and ISO run 100 → 3200 → 100 (~19.8–23.7 s), showing +/− disabled states at range ends.
- 32.5–35.5 s — Auto clicked: ring springs f/1.5 → f/2.0 with visible overshoot (passes 2.0 at ~300 ms, peaks f/2.2 at ~700 ms, back to f/2.1, settles 2.0) — spring with ~10% overshoot, ~1.2 s settle. Meter needle moves with orange motion-trail ghosts (2–3 fading afterimages, ~120 ms decay).
- 37.5–53 s — more drag/stepper permutations proving Auto only drives the ring while respecting current shutter/ISO.
- 53.9–55.3 s — final Auto click: f/3.0 → f/2.8, ~400 ms ease-out, needle lands dead center in the peach zone; loop-clean end state.

## Why saved
No owner note. This is the taste profile's core pattern at component scale: motion that SHOWS the feature instead of describing it. The scripted intro is a complete product story in 4 seconds — problem (closed, dark, -3), transformation (bloom to f/1.4, overexposed +3), resolution (Auto solves to 0) — and "any touch cancels" makes the demo respectfully interruptible. The craft moves a generic AI build would miss: the numbers rotate under a fixed index (real aperture-ring physics) instead of a needle spinning over a static scale; the iris hole's fill IS the exposure preview; Auto answers with a physical spring-overshoot as if a motor snapped the ring into place; the meter needle leaves motion trails; drag yields continuous fractional f-stops while steppers stay discrete; mono digits everywhere prevent value-width jitter; and one orange accent carries the entire semantic load (current value, needle, target zone, Auto state) on an otherwise gray/black system.

## Extractable rules
- Open a self-demo component with a scripted 3-beat choreography (problem ~2 s, hold ~0.9 s, resolve ~0.7 s) and cancel it on any pointer-down.
- Rotate the value ring under a fixed 12-o'clock index tick; never spin a pointer over a static scale when mimicking hardware.
- Encode system state in the illustration's fill (iris hole: #4a4a4e closed → #fff overexposed), not only in numeric readouts.
- Animate programmatic corrections (Auto) with a spring, ~10% overshoot, ~1.2 s settle; animate user drags 1:1 with zero smoothing.
- Give direct-manipulation controls continuous fractional values; give stepper controls discrete stops; never mix within one control.
- Set every numeral in monospace with slashed zeros so live values never cause layout jitter.
- Use exactly one accent (orange ~#f2760f) for all "current/active/target" semantics on a neutral gray + near-black palette.
- Mark the target zone on a meter with a fixed accent-tinted rounded rect (accent @ 16% alpha) so "correct" is visible before the needle arrives.
- Add 2–3 fading afterimage ghosts (~120 ms decay) to fast needle movements to sell velocity.
- Nest a white content panel (radius 20px) inside a gray card shell (radius 28px), leaving a bottom chin strip for the hint caption.
- Show mode engagement as a small accent dot inside the pill button, and clear it the instant the user overrides manually.
- Dim stepper glyphs to ~#c2c2c6 at range ends instead of hiding them.
