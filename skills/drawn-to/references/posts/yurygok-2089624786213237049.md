# Dark AI-infra dashboard card quartet

## What we see
Four standalone dark-mode dashboard cards for a fictional AI-gateway product, each shot on a near-black canvas (#101012): a rate-limit dial control ("Rate ceiling"), a Sankey request-router ("Request routing"), a Gantt job scheduler ("Schedule"), and a spend forecaster ("Cost forecast"). All four share one strict card grammar — header breadcrumb, hero stat, full-bleed visualization, detail table, status-line footer with pill actions — while each swaps in a different visualization type. No tweet text; the images are the whole post.

## Layout & composition
- Single centered card per frame: ~1790–1800 x 1770–1920 px on a 3903x2928 canvas (2x export → ~900 x 890–960 design px at 1x).
- Card radius ~20–24px (1x); no outer border or shadow — the card separates from the #101012 canvas purely by being 4–8% lighter.
- Interior is sectioned, not padded sub-cards: full-bleed horizontal bands separated by 1px hairlines (~#2A2A2A). Band grays step lighter downward: ~#1C1C1C (viz/grid zone) → #212121 (header/stat) → #29292B → #313133 (table/footer tiers).
- Content inset ~28px (1x) left/right, consistent across all bands; header band ~56px tall.
- Card 1 viz zone sits on a blueprint grid: ~56–64px square cells at ~8% white, with small "+" crosshair marks in the zone's corners.
- Stat rows use vertical hairline dividers into 3 equal columns (card 1); tables are borderless rows with generous ~44px row height (1x).

## Card anatomy
Identical 5-band skeleton on all four cards, roughly: header 8% / hero stat 12% / visualization 42% / detail 24% / footer 14% of card height.
- Header: sans title ("Rate ceiling") + "/" + muted breadcrumb ("gateway · prod"), right side meta (LIVE badge, "LAST 5 MIN", "30D" chip) + 32px ellipsis circle button.
- Hero stat: ~40px numeral with dimmed unit glyphs — "$" prefix and "M" suffix rendered at ~40% opacity ("1.13M", "$2,180", "4h 12m"); right-aligned secondary stats (P50 240ms · ERR 0.41%; "1 failed · 1 running").
- Visualization band: dial cluster / Sankey / Gantt / area chart — one type per card, never mixed.
- Detail band: keyed table (colored dot bullets matching viz hues, columns REQ / P95 / SHARE), "TOP DRIVERS" rows with mini bar-sparklines and signed colored deltas, or a failed-job sub-card (radius ~12px) with its own Retry button.
- Footer: left = monospace uppercase status string ("APPLIES WITHIN 30s", "WEIGHTED · STICKY SESSIONS ON", "AUTOSCALE ON · 3 WORKERS", "MODEL REFIT 04:00 UTC"); right = secondary dark pill (#2C2C2C) + primary white pill (~#E9E9EB, dark text). Full pill radius.

## Type & color
- Two-voice type system: neutral grotesque sans for titles (~22px medium) and prose (~15px, ~#9A9AA0 on dark), monospace for ALL data — numerals, axis labels, chips, footer status — uppercase mono labels tracked ~+8–12%.
- Hero numerals ~40px in off-white #E8E8E8; muted text tiers ~#6E6E72 and ~#4A4A4E.
- Neutrals: canvas #101012, band grays #1C1C1C→#313133, hairline #2A2A2A.
- Accents (sampled): amber #F0A818, lime #A8F048, blue #4890F0, purple #7848F0, red ~#E5485A (failed), all on ~5–10% tinted dark chip backgrounds when used as labels.
- One-accent-per-card discipline: amber owns card 1, lime owns cards 3–4; the full categorical set (blue/lime/purple/amber) appears only where semantically required (Sankey destinations), and each hue is repeated in the legend dots and table bullets.
- Semantic color held consistent across cards: lime = live/running/actual, red = failed, amber = budget/warning/delta-up-cost, blue = cost decrease.

## Graphic language
Instrumentation as illustration — every feature is depicted by a working-looking chart, not decoration:
- Analog dial cluster (burst / ceiling / shed) on a blueprint grid, active dial wrapped by an amber sweep arrow annotated "620 rps" in mono — a physical-control metaphor for a rate limiter.
- Sankey with 3 gray source stubs flowing to 4 colored destination bars; inactive flows at ~6% white, one highlighted flow in blue.
- Gantt encodes state by fill treatment: solid gray = done, lime gradient = running, red outline + inline "EXIT 137" chip = failed, dashed outline = queued; dashed vertical now-line with a lime "NOW 14:18" chip.
- Area chart switches line style at the present: solid lime + gradient fill (actual) → dashed (forecast), dashed amber budget line with an anchored "BUDGET $2,400" chip, gray tooltip chip "aug 16 $1,412" pinned to the boundary point, p10–p90 band in legend.
- The numbers reconcile: 450K+330K+255K+95K = 1.13M; 40+29+23+8 = 100%; 418/620 ≈ 67%. Copy is plausible ops telemetry ("exit 137 · oom at 08:41 · retry 2 of 3").

## Why saved
No owner note. This is a reference-grade example of the owner's editorial-dark, design-engineer lane: a single reusable card grammar that scales across four completely different visualization types without breaking rhythm. The craft that earns the save, which generic output would miss: unit glyphs dimmed inside hero numerals ("$2,180", "1.13M"); job state encoded by fill treatment (solid/gradient/outline/dashed) instead of four arbitrary colors; line style flipping solid→dashed exactly at the now boundary; label chips anchored to their reference lines; borderless section separation via stepped grays + 1px hairlines; mono-vs-sans as a strict data-vs-prose voice split; footer status strings written like real telemetry; and internal arithmetic that actually adds up. It shows the feature (dial it, route it, schedule it, forecast it) rather than describing it.

## Extractable rules
- Set canvas #101012 and separate card sections with stepped grays (#1C1C1C→#313133) plus 1px #2A2A2A hairlines — no borders, no shadows.
- Reuse one card skeleton everywhere: header / hero stat / viz / detail / footer at roughly 8/12/42/24/14% of height, 28px side inset.
- Render hero numerals at ~40px and dim unit glyphs ($, M, %, h/m) to ~40% opacity.
- Set all data in monospace and all prose in a grotesque sans; track uppercase mono labels +8–12%.
- Give each card one accent (amber #F0A818 or lime #A8F048); unlock the categorical set (blue #4890F0, purple #7848F0) only for multi-series encodings.
- Keep semantic hues fixed across the system: lime=live/actual, red=failed, amber=budget/warning.
- Encode process state by fill treatment: solid=done, gradient=running, red outline+inline label=failed, dashed outline=queued.
- Switch chart line style solid→dashed at the present moment and mark it with a dashed vertical now-line plus a mono time chip.
- Anchor value chips directly to their reference lines (BUDGET $2,400 on the budget line, tooltip at the actual/forecast joint).
- Make every visible number reconcile (rows sum to the hero total, shares sum to 100%).
- Footer = mono uppercase status string left ("AUTOSCALE ON · 3 WORKERS") + dark pill secondary and white pill primary right.
- Lay technical zones on a ~56–64px blueprint grid at ~8% white with "+" crosshairs in the corners.
