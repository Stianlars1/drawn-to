# Monochrome isometric service cards, built for animation

## What we see
A "Services" section from a design agency website: five feature cards in a 3+2 grid on a near-black canvas, each headed by a custom isometric line illustration (branding artboards, exploded UI layers, a PCB "product" board, a draped landing-page sheet over bar columns, a curving page-ramp with framework logos). Every card follows title → illustration → paragraph → pill tag cloud. Tweet text: "illustrations from our new website. / ready for animation 😉" - the illustrations are layered vector constructions explicitly staged for future motion.

## Layout & composition
- Section: full-bleed dark container #232323, corner radius ~33px, inset ~18px from an #EFEFEF page frame; internal side padding ~90px.
- Content width ~1224px. Row 1: three equal cards 392px wide × 435px tall. Row 2: two cards ~596px wide × 340px tall. Uniform gap 24px both axes (asymmetric grid: 3-up detail cards, 2-up wide cards).
- Cards: fill #2E2E2E (only +4-5% lighter than the #232323 page - a whisper of separation, no visible border, no shadow), radius ~16px, padding ~24-28px.
- Centered section header block: H2 + 2-line subtitle, ~90px above the grid.
- Illustrations bleed to the card's top/side padding and sit behind faint diagonal dashed guides that run edge-to-edge, tying illustration space to card space.
- Wide row-2 cards carry an additional full-card 45° diamond crosshatch texture (#303030-#3A3A3A lines on #2E2E2E, ~4px pitch) fading toward the bottom.

## Card anatomy
- Visual-to-text ratio ~55:45 in row 1 (illustration zone ~260px of 435px); row 2 puts the illustration on the right half so text and chips left-align in the remaining column width.
- Order: bold title top-left (22-24px), isometric illustration filling the upper region, 4-6 line description in mid-gray, then 1-2 rows of pill chips bottom-anchored.
- Chips: fill #232323 (reuses the page-bg token, so chips read as "punched holes" in the card), pill radius, ~26px tall, ~14px horizontal padding, 8px gaps; label ~11px/700 uppercase #EFEFEF, letter-spacing ~0.3px. Chips double as tech-stack metadata (FIGMA, NEXT.JS, RIVE, LOTTIE...).
- Per-card illustration: Branding = isometric artboard diamond with pure-white logo mark + stipple-textured letterhead + business card, Figma-style corner selection handles; Product UI/UX = three exploded parallel UI planes (hatched wireframe → tile grid → toolbar layer) with a dotted leader line to a tiny "px" annotation; Full-stack = product-as-PCB: circuit board with mounted UI screen, hex chip package, code-bracket panel, hatched pin rows; Landing pages = flexible page sheet draped over rising isometric bar columns (page conforms to growth metaphor); Full websites = browser page curving up a ramp of fanned page fins, with Next.js wordmark, Framer bolt, and Webflow logos embedded as diegetic screen content.

## Type & color
- Strictly monochrome, zero accent hue. Page #232323, card #2E2E2E, chip #232323, frame #EFEFEF.
- Text: H2 "Services" ~36px/700-800 #EFEFEF; card titles 22-24px/700 #EFEFEF; body ~15-16px/400 #9D9D9D, line-height ~1.45-1.5; chip labels ~11px/700 uppercase #EFEFEF.
- Illustration strokes use a 3-tier gray ramp: faint guides/dashes ~#3A3A3A-#4A4A4A, structural outlines ~#6E6E6E-#8A8A8A, focal elements (logo mark, toolbar pill, selection handles) #EFEFEF up to pure #FFFFFF - brightness = importance, so each illustration has one white focal point.
- Grotesque sans throughout (Aeonik/Inter-like), tight tracking on headings.

## Graphic language
Isometric (≈2:1, 26.6°) technical line-art, drawn like annotated blueprints of the deliverable itself. Construction details: square selection-handle nodes on artboard corners (Figma vocabulary); dotted leader lines with measurement labels ("px"); dashed diagonal iso-guides extending past objects into the card; three fill textures - 1px directional hatching, noise/stipple dither (letterhead portrait, panel fills), and fine diamond crosshatch as card-level ground texture. Real tool logos (Next.js, Framer, Webflow) appear inside the illustrated screens rather than as badge rows. Everything is stroke-based and layered in discrete planes - exploded layers, draped sheets, fanned fins - i.e., pre-separated parts that can slide/assemble, which is what makes them "ready for animation."

## Why saved
No owner note. This is a direct match for the owner's core taste: illustration/vector-driven feature storytelling in editorial dark UI, explicitly "ready for animation" - the same phrase the owner uses for their own website illustrations. The craft that earns the save: (1) a disciplined 3-tier gray ramp inside the illustrations so hierarchy exists without any color; (2) card/page/chip all built from just two grays 4% apart - chips reuse the page token to read as recessed; (3) illustrations that depict the service as a mechanism (UX = exploded layers, full-stack = PCB, landing page = sheet over growth bars) instead of generic clip-art; (4) meta design-tool vocabulary (selection handles, px annotations, iso guides) that signals design-engineer authorship; (5) every asset drawn as separable planes so animation is an assembly problem, not a redraw. A generic AI page would use colored gradient icons, visible card borders, and decorative rather than mechanistic illustrations.

## Extractable rules
- Separate card from page with a 4-5% lightness step only (#232323 → #2E2E2E); no border, no shadow.
- Fill tag chips with the page background token so they read as punched-through holes in the card.
- Build illustrations on a 3-tier gray ramp: ~#3F3F3F guides, ~#7A7A7A outlines, #EFEFEF-#FFF for exactly one focal element per illustration.
- Draw feature illustrations as isometric 2:1 exploded mechanisms of the actual deliverable, not decorative icons.
- Extend dashed iso-guides beyond the illustration to the card edges to fuse illustration and layout space.
- Use design-tool vocabulary (corner selection handles, dotted leader lines, "px" labels) to signal craft to a design-literate audience.
- Mix three monochrome textures for depth: 1px directional hatch, noise stipple, and ~4px diamond crosshatch at ≤8% contrast.
- Grid: 3 equal cards (≈392px) for core services, then a 2-up row of wide cards (≈596px) for broader offerings; uniform 24px gap.
- Radii scale: section ~33px → card 16px → chip pill; padding ~24-28px inside cards.
- Type scale: 36/700 section title, 22/700 card title, 15-16/400 body at #9D9D9D, 11/700 uppercase chips at #EFEFEF.
- Embed real tool logos inside the illustrated screens (diegetic) instead of a separate logo strip.
- Draw every illustration as discrete separable planes so the animation pass is assembly (slide/converge/draw-on), not redraw.
