# QI - illustration proposals in two passes

Use this when the owner needs a new illustration direction or unresolved scene
choices. Existing approved sets skip those questions; implement and verify the
accepted contract. Explicit delegation lets the agent choose remaining details
within scope and record the reason. It does not require a fresh interview.

The build method and device catalog live in [illustration-ideation.md](illustration-ideation.md).
Use its claim-to-scene ladder for explanatory features. Brand, character,
landscape, collection and identity work use the matching role criteria in
[quality-bar.md](quality-bar.md) and [september-expansion.md](september-expansion.md).
No role requires an invented antagonist, metric or technical device.

## Pass 1 - choose the whole-set direction

When the direction is open, offer a few genuinely different whole-set approaches.
Choose relevant methods from [practitioner-methods.md](practitioner-methods.md):
M1-M5 cover technical/explanatory systems; M6-M9 cover character, identity,
editorial terrain and moving collections. The method is a way to generate the
work, not a requirement to offer every lane.

Each option names one coherent material/register and sketches how it serves the
whole set. The owner may combine weighted ingredients; make their roles explicit
before recording the chosen contract. One register is a valid result.

```text
For the three product features, which whole-set direction fits best?
A. Self-demonstrating UI: capture shows input, search shows a result, sync shows the same record reaching its destination.
B. Paper mechanisms: one drawing language presents a receiver, a search instrument and a connected pair.
C. Technical plates: three numbered diagrams explain each feature with the same line and annotation system.
Choose or combine; we will carry the selected material through all three.
```

Record the relationship as independent claims, sequence, shared world,
collection or identity system. For a landscape or character set, sketch poses,
crops and reading-space relationships instead of forcing three mechanisms.

## Pass 2 - choose scenes inside the approved direction

Offer alternatives only for scenes that remain unresolved. Preserve the chosen
register, material and method while changing relevant content, objects,
composition or claim expression. The reframing operators in illustration-ideation
can vary explanatory topology; a topology need not change merely to fill a menu.

```text
For verification, within the approved paper mechanism direction:
A. A gate admits the verified document; an unverified one waits outside.
B. A cutaway exposes the checks along the document's route.
C. Two connected stages show that document before and after verification.
Choose or combine. The alternatives change the explanation, not the material.
```

A scene table makes the difference between options concrete:

| Option | Role/claim | Composition or topology | Method/register | Main object/content | Relevant test | Build cost |
|---|---|---|---|---|---|---|
| A | | | | | | |
| B | | | | | | |

For explanatory alternatives, avoid offering the same explanation with only
labels changed. Within a sequence, preserve the recurring object and compare
the transition/order instead. Within a collection, compare selection, aperture,
crop and protected reading space. Shared worlds and identities keep their
recognizable coordinates or atom; variety is not a ban on repetition.

## Tests and recording

- **Independent feature claims:** read back what each image explains. Swap it
  onto a sibling claim and check for a meaningful mismatch. A shared primitive
  is legitimate when its role differs; do not impose different devices or loop
  rhetoric solely to achieve uniqueness.
- **Sequence/preview:** use order and continuity. The same object may recur at
  the same size in the same frame, changing only the state that matters.
- **Collection/identity/shared world:** check coherent treatment, recognizable
  content and the intended relationship. Record these results, not a fictional
  swap failure.
- **Brand/character/landscape:** check silhouette, composition, material, crop
  and reading space. Use the relevant QA role; no explanatory claim is required.
- Name a motion opportunity only when it is useful and allowed by the motion
  budget. Otherwise record static. For animation, name a composed poster and
  inspect the full motion envelope; do not require the poster to be the final
  frame or assume every screenshot will capture it.
- Estimate build cost for the actual medium. A small SVG, a layered animated
  scene and a raster landscape have different costs. Element counts may help
  scope vector work, but are not cross-medium complexity measurements.

Evidence chips are one optional hardware/technical treatment from
`local-feature-graphics`: a compact claim plus proof line, sometimes with a
semantic icon, anchored near the main object. Add them only when they contribute
real information; their count, overlap and emphasis follow the approved composition.

Record accepted choices in [lock-file.md](lock-file.md). Each applicable QI row
names the role/claim, scene, material, static/motion choice and relationship-specific
test result. An order or consistency result is as complete as a swap result.
Revisions that change the approved direction return to that decision; routine
implementation choices do not reopen Pass 1.

## Worked reframing exercise - several explanations of breadth

For "connects to two hundred sources", a tile grid, receding catalog and tiled
plaza all emphasize abundance. They can be useful composition/material options.
If the task is instead to explore different *explanations*, try:

- **Inversion:** one connector you would build and the 199 you would not;
  compare the effort with the same unit.
- **Consequence:** one query returns a merged answer from many sources.
- **Container:** one socket accepts any of the supported plugs.
- **Obstacle removed:** a request crosses the integration backlog in one step.

Keep the material fixed while varying the explanation in Pass 2. Pass 1 may
compare different materials across the whole set. Neither pass requires a
different register for every selected feature.
