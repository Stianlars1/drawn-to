# Graphic Language - How Features Are Depicted Non-Verbally

Synthesized from 45 reverse-engineered references. Citation ids = author + leading digits of the post id (7 digits where an author has colliding prefixes). UNIVERSAL = pattern present in a large share of the corpus (count given). FAMILY = trait of one visual family only.

## 1. The dominant device: UI-fragments as illustration - UNIVERSAL, 28/45

23/45 references use `ui-fragment` as their primary illustration axis (LexnLin-2024, basit_designs-2017, AlexandruDranga-2090, piyushsphere-2088, adriankuleszo-2089887, _heyrico-2090, mnowakdesign-2089321, designbynavneet-2089, yurygok-2089981, _heyfaisal-2089734, mnowakdesign-2089684, ImranUxi-2089, flornkm-2089, LexnLin-2089, toolfolio-2089, jeetnirnejak-2089, insporadesign-2088, cabralorenzo-2090, yurygok-2089624, Triopixels-2089, adriankuleszo-2089328, adriankuleszo-2089253, mickces-2088); 5 more use the device under a different primary axis (0xSero-2090, adriankuleszo-2090, piyushsphere-2089, helvetiica-2089, kevserctk-2090). **Zero references in the corpus depict a feature with an icon + blurb, stock illustration, or abstract metaphor.** The feature is always shown as the product doing the feature: a real kanban dragging a card (AlexandruDranga-2090), a radar instrument with orbiting contacts (basit_designs-2017), a code window mid-string-swap (piyushsphere-2089), an invoice table as the hero's only "product shot" (adriankuleszo-2090). Fragments are rendered at real-component fidelity: hairline borders, layered chips, avatar rings, speech-bubble tails (LexnLin-2024). Fragments are typically oversized - cropped at ~80% scale by the container (basit_designs-2017), never full shrunken screenshots (_heyrico-2090).

### 1a. Diegetic product chrome - 9/45
The product's own interaction chrome is the drawing vocabulary: Figma-style blue corner selection handles and 2px dashed marquees (adriankuleszo-2089887), square selection-handle nodes + dotted "px" leader lines (marcelkargul-2090148), 1px dashed gold crop-mark borders whose dashes overshoot corners plus ~7px solid #937d46 corner squares (AlexandruDranga-2090), an I-beam cursor frozen mid text-selection with a tooltip chip (piyushsphere-2089), dashed selection frames + live px readouts (GrahamPaterson-2089), cyan rgba(34,211,238,0.35) padding overlays with mono value pills (ImranUxi-2089), ⌘K keycap chips (mnowakdesign-2089684, designbynavneet-2089). Named multiplayer cursors (small colored arrow + dark 11px pill label, one warm / one cool) recur as the humanizing signature (basit_designs-2017 "Steve"/"Meghan", adriankuleszo-2089887 role-labeled cursor bubbles). Recorded or simulated cursors drive ~12 demos - the cursor is part of the composition, drawn oversized (~56px black arrow with white outline, _heyfaisal-2089369).

### 1b. Skeleton fragments with only selling data rendered - 3/45, high-leverage
Gray-bar every element except the 3–5 data points that sell the feature; reserve the accent for exactly those (LexnLin-2089: "Good morning", 128 / 1,156 / 24h, +12%, 68% ring in blue on gray skeleton). Skeleton-line phone mockups with only the focal card rendered (adriankuleszo-2089887); skeleton sections at #F5F5F5 with #9CA3AF labels as documentation canvas (GrahamPaterson-2089).

### 1c. Product-truthful content - 13/45
The fragment's content is real, not lorem: literal shell commands with only the "$" tinted green ("$ prime env init"), real hyperparameters (max_steps 10,000, learning_rate 0.00005) (0xSero-2090); versioned filename "client-delivery-v3.zip" (AlexandruDranga-2090); numbers that reconcile - 450K+330K+255K+95K = 1.13M, shares sum to 100%, 418/620 ≈ 67% (yurygok-2089624); plausible ops telemetry "exit 137 · oom at 08:41 · retry 2 of 3" (yurygok-2089981); real model strings `openai/gpt-4o` → `anthropic/claude-3-5-sonnet` (piyushsphere-2089); live Hz/duration rows with sweep notation "900→500 Hz" (mickces-2088); real CRM step copy "Enrich lead data via API" (_heyfaisal-2089734); zero lorem in product mocks (designbynavneet-2089); Enter-key hint inside a Generate button (basit_designs-2017). Content fidelity IS the visual style.

### 1d. Cropped / edge-bled fragments implying a larger canvas - 10/45
Fragments bleed off 1–2 container edges to force scale and imply continuation: icon rails cropped both sides, chat windows cropped right+bottom (_heyrico-2090); variant carousels with outermost items gradient-masked to 0 (adriankuleszo-2089887); UI shot bleed-cropped to two edges exposing one ~8px rounded corner (piyushsphere-2088); logo rows opacity-ramped 1.0 → 0.35 toward both edges to imply an infinite marquee (piyushsphere-2089); paper stacks alpha-mask-faded over the last ~40% instead of hard-cropped (adriankuleszo-2090); a stray corner-handle square floating off-card implying an off-screen canvas (AlexandruDranga-2090); brand marks cropped by panel edges (devxnuj-2090, helvetiica-2089).

### 1e. Opacity hierarchies - 9/45
Exactly one full-contrast hero per scene; everything else ghosted: alternates at 15–30% (adriankuleszo-2089887), stacked rear cards at 25–40% (0xSero-2090), row-state stagger 100/60/35% implying scroll position (xchylerdrenth-2090), stack depth 1 / 0.7 / 0.45 (Triopixels-2089), inactive index rows 45% (piyushsphere-2089), non-active carousel slides 35% (ImranUxi-2089), disabled chevrons 25% (insporadesign-2087), trailing headline phrase 55% (basit_designs-2089995). Depth by dimming, never by shadow or blur (0xSero-2090).

## 2. Line-art & blueprint - FAMILY (blueprint/editorial-dark), ~11/45

- **Mechanism diagrams, not decoration - 7/45.** Draw the feature's literal mechanism in 1px line-art: isometric ≈2:1 (26.6°) exploded planes of the deliverable itself - UI layers, PCB-as-product, draped sheet over growth bars - pre-separated for animation (marcelkargul-2090148); hub-and-spoke agent diagrams with dashed orbits and connector lines, doc pipelines feeding skeleton cards (LexnLin-2089); a diamond state machine annotated with real CLI commands, a wireframe globe with routed white segments (0xSero-2090); node maps with dotted bezier connectors and 28–36px icon chips (adriankuleszo-2089328); a router diagram with real model-name pills (_heyfaisal-2089734); a 9-line connector fan where exactly one line is accent blue #34a2d5 among cool-gray #ccd6e2 siblings (adriankuleszo-2090); a failover chip-graph on 1px 4/4 dashed connectors (piyushsphere-2089). xchylerdrenth-2090 extends this to generative abstraction: barcode width-gradients as an easing curve made physical, a sphere drawn from ~30 dot-terminated range lines.
- **FIG-plate labeling & spec numbering - 6/45.** FIG.1–FIG.4 plate labels in 11px mono #454545, 16–20px from the card corner, plus triple numbering (nav 01–04, sections 01/02, specs 1.1–2.3) (0xSero-2090); mono spec-index 1.0/1.1/1.2 (piyushsphere-2089); "→ 0.1"…"→ 0.5" cell indices (xchylerdrenth-2090); "fig. 01 - bloom" ledger rows and 01/02/03 chips in 1px circles (devxnuj-2090); slashed-zero "01 / 03" series counters (piyushsphere-2088).
- **Gray-ramp tiers inside illustrations - 4/45.** 3-tier: ~#3F3F3F guides / ~#7A7A7A outlines / #EFEFEF–#FFF for exactly ONE focal element per illustration (marcelkargul-2090148); 4-step #fff > #929292 > #555 > #202020 doing all hierarchy (0xSero-2090); 6-value ramp #323335 → #c9c9c9 (xchylerdrenth-2090). Brightness = importance; color unnecessary.
- **Design-tool measurement as ornament - 11/45.** Dotted leader lines between mono keys and values (0xSero-2090, yurygok-2089981), dashed iso-guides extended past objects to card edges (marcelkargul-2090148), blueprint grids with "+" registration crosshairs in zone corners (yurygok-2089624 ~56–64px cells at 8% white; yurygok-2089981 ~40px at 4% white), 1px corner-only bracket frames with ~40px arms + status dots (recentdesign-2089), an offset 1px hairline bracket ~12px outside the card closed by 1.01 hover scale (insporadesign-2088), hairline grids that deliberately overshoot content bounds plus dashed register frames (xchylerdrenth-2090), exposed full-height column rules with 45°-hatched or 8px-pitch-ruled ~48px gutters (designbynavneet-2089).
- **Grid-texture placement rule.** Blueprint/dot grids are confined and faded: outside the content container only, at ~5% contrast (LexnLin-2089); radially faded band behind the illustration only (adriankuleszo-2090); ~28px white grid at rgba(255,255,255,0.5) masked to the gradient zone (Triopixels-2089); 20px graph-paper strip fading out at the bottom of its slot (piyushsphere-2089 light mode).

## 3. Texture layer - UNIVERSAL for gradients (11/45 grain), FAMILY for print artifacts

- **Grain on every large gradient - 11/45.** 2–3% monochrome grain over all gradients, visible at 4x zoom, kills banding + adds print feel (devxnuj-2090); stipple noise σ≈4–6 (piyushsphere-2088); 4–6% film grain baked into the shader so blur reads as lens defocus (insporadesign-2087); ~20% noise on mesh shapes (kail_designs-2089); grain toggle as a first-class tool parameter (alaymanguy-2088); film grain as the unifying finish over 3D dashboard reels (mnowakdesign-2089684); 2–3% grain on illustrated paper so input reads physical vs clean output UI (adriankuleszo-2090). Deliberate exceptions: zero grain on premium glow shaders where perfectly smooth falloff is the point (madebylalit-2088, its_sslvr-2088).
- **Halftone screens - 3/45.** Black square-grid dots, pitch ~8px, dot ~3px (~30% coverage), no rotation, clipped to exact rectangles over the hottest gradient zone = "printed ink" (basit_designs-2089995); ~4px woven halftone/CRT mesh over blurred photo (_heyrico-2090); perspective CRT dot-matrix where each dot is an RGB sub-pixel cluster, hero band only (0xSero-2090).
- **Pixel dither / mosaic - 3/45.** 2–3px random dithered square field, density fading downward, as a dark-mode texture strip (piyushsphere-2089); ~8–10px pixel-mosaic grid with hairline cell lines converting a photo into an owned brand asset (kevserctk-2090); pixel-dithered logo mark (_heyfaisal-2089734).
- **Dot grids - 5/45.** ~2px dots at ~19px pitch, bg −7% luminance, radially faded (adriankuleszo-2090); ~2px at ~32px pitch #D8D6D1 on warm off-white (cabralorenzo-2090); ~14pt-pitch dot matrix that ripples as feature feedback (helvetiica-2089); dot-grid under focal objects (adriankuleszo-2089887); 1px speck grid at ~14px pitch on ONE panel per board only (basit_designs-2089995).
- **Hatch / stipple / crosshatch - 2/45.** 1px directional hatch + noise stipple + ~4px diamond crosshatch, all ≤8% contrast (marcelkargul-2090148); 45° gutter hatching (designbynavneet-2089).
- **Sheen stripes.** 45° soft diagonal bands ~60px wide at 6–10% white alpha over gradient slabs (basit_designs-2089995).
- **Contrast ceiling - universal.** Texture never exceeds ~8% contrast against its ground (marcelkargul-2090148, LexnLin-2089, basit_designs-2017 dividers at +5 luma); texture is felt, not seen.

## Rules

1. Depict every feature as the product performing it - a working UI fragment, mechanism diagram, or instrument. Never an icon + blurb, never stock illustration, never abstract metaphor (28/45; 0xSero-2090, adriankuleszo-2089887, LexnLin-2024).
2. Render fragments oversized and crop them off 1–2 container edges (or gradient-mask the outermost items to 0) to imply a larger canvas; never shrink a full screenshot to fit (_heyrico-2090, adriankuleszo-2089887, piyushsphere-2088).
3. Allow exactly one full-contrast hero per scene; ghost alternates to 15–40% opacity and encode stack depth as opacity steps (1 / 0.7 / 0.45), not size (adriankuleszo-2089887, 0xSero-2090, Triopixels-2089).
4. In mock dashboards, skeleton-gray every element except the 3–5 selling data points, and give ONLY those the accent hue (LexnLin-2089).
5. Fill fragments with product-truthful content: real commands with only "$" tinted green, real hyperparameters, versioned filenames ("client-delivery-v3.zip"), and numbers that reconcile (rows sum to the hero total, shares = 100%) (0xSero-2090, AlexandruDranga-2090, yurygok-2089624).
6. Use the product's own chrome as drawing vocabulary: blue corner selection handles, 2px dashed marquees, I-beam cursors frozen mid-action, version pills, named multiplayer cursors (11px pill label, one warm + one cool) (adriankuleszo-2089887, basit_designs-2017, piyushsphere-2089).
7. Draw line-art illustrations on a 3-tier gray ramp - ~#3F3F3F guides / ~#7A7A7A outlines / #EFEFEF–#FFF - with exactly one white focal element per illustration; 1px strokes, geometric nodes 8–10px, depth via 25–40% opacity dimming, never shadows (marcelkargul-2090148, 0xSero-2090).
8. Draw mechanisms, not decoration: exploded isometric 2:1 planes of the deliverable, hub-and-spoke diagrams with dashed orbits, state machines annotated with real commands; build each as discrete separable planes so animation is assembly, not redraw (marcelkargul-2090148, LexnLin-2089, 0xSero-2090).
9. Label plates and specs with a mono numbering system: "FIG.1" in 11px mono #454545 16–20px from the corner, plus 01–04 / 1.1–2.3 cross-references, or slashed-zero series counters "01 / 03" (0xSero-2090, piyushsphere-2088, devxnuj-2090).
10. Deploy design-tool measurement as the only ornament: dotted leader lines between mono keys and values, dashed guides extended past the object to the container edge, cyan padding overlays at ~35% alpha, live px readouts in mono pills, "+" crosshairs in blueprint-grid corners (ImranUxi-2089, marcelkargul-2090148, yurygok-2089624).
11. Confine blueprint/dot-grid textures to a faded band behind or outside the content (radial or linear fade), 40–80px cells at 4–8% contrast - never full-bleed at full strength (LexnLin-2089, yurygok-2089981, adriankuleszo-2090).
12. Overlay 2–6% monochrome grain (noise σ≈4–6) on every large gradient to kill banding and add print texture; skip grain only on premium glow shaders where smooth falloff is the point (devxnuj-2090, piyushsphere-2088, insporadesign-2087; exception madebylalit-2088).
13. For print-authority moments, clip a black halftone screen (8px pitch, 3px dot, square grid, no rotation) to an exact rectangle over the hottest gradient zone; add 45° sheen stripes ~60px wide at 6–10% white alpha (basit_designs-2089995).
14. Process photographic assets into owned textures - pixel-mosaic grids (~8–10px cells), 2–3px dither fields, ~4px halftone mesh - rather than pasting raw photos or naked gradients (kevserctk-2090, piyushsphere-2089, _heyrico-2090).
15. Keep page chrome grayscale and quarantine ALL chroma inside one signature image/shader/texture asset; reuse that single asset at ≥3 scales (hero, card surface, footer banner) to bind the page (kevserctk-2090, _heyfaisal-2089734, basit_designs-2089995).
16. When using blurred photography under flat UI, push blur to 40–80px, then re-texture with grain or halftone, and park the composition's dark mass behind the text block so white type survives without a scrim (_heyrico-2090, insporadesign-2087).
17. Match photo mood to theme (amber dusk = dark mode, green daylight = light mode) and re-derive component materials per theme: black 45–60% + backdrop-blur glass over photos in dark; solid white + soft ambient shadow in light. Never recolor one asset (piyushsphere-2089).
18. Use art/texture as a matte or frame only - 80–140px around the product window, with frosted chrome (blur ~20px, ~60% white) sampling the backdrop hue; texture never runs behind text (designbynavneet-2089).
19. Render goo/liquid accents as 2px gradient strokes on the metaball seam (feGaussianBlur ~8–12 + feColorMatrix ~18/−7), brightest at the pinch and fading to transparent; let overlay data refract through deforming material (arknow91-2089, recentdesign-2089).
20. Add at most one specular 3D object per composition - chrome sculpture, metal chip, glass prism - cropped by a frame edge, moving at constant velocity, as material counterpoint to matte surfaces; render the same logo in two materials (flat ink in nav, brushed metal in illustration) instead of two colors (AlexandruDranga-2090, basit_designs-2017, adriankuleszo-2090).
21. Invent one fictional client brand per page and thread its mockups through every card; salt with 9:41 status bars, percentages, bit-counts, and diegetic microcopy inside the fake UI instead of captions (adriankuleszo-2089887, _heyrico-2090).
22. Use real third-party logos (full color inside white squircle tiles, radius ≈28%) for integration stories, embedded diegetically inside the illustrated screens; tint trust-bar logos one gray (#7E8AA0-class) and optically size-match them (_heyrico-2090, marcelkargul-2090148, adriankuleszo-2089253).
23. Contrast materials to tell before/after: grainy, 2–6°-rotated, page-curled paper = messy input; crisp borderless white card = product output; z-order and vertical position diagram the pipeline (adriankuleszo-2090).
24. Fade, never hard-crop: dissolve marquee edges with ~60px mask-image gradients, alpha-mask illustration stacks over their last ~40%, opacity-ramp repeated logo rows 1.0 → 0.35 toward both edges (LexnLin-2024, adriankuleszo-2090, piyushsphere-2089).
25. Repeat one compositional signature across a set (3-item diagonal stagger at ~50px x-offset per step, identical card geometry, one shared accent motif) so five cards read as one system; allow exactly one dark #333 anchor element per set (_heyrico-2090).
