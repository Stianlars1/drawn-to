# Reference captures - third-party material

The five JPEGs in this folder are cropped, downscaled captures of published
landing pages, kept as **design reference plates** for the analysis in
`references/hero-atmosphere.md` and `references/posts/local-production-heroes.md`.

| File | Page | Captured |
|---|---|---|
| `antigravity-hero.jpg` | antigravity.google | 2026-08-21 |
| `codex-hero.jpg` | openai.com/codex | 2026-08-21 |
| `linear-hero.jpg` | linear.app | 2026-08-21 |
| `raycast-hero.jpg` | raycast.com | 2026-08-21 |
| `vercel-hero.jpg` | vercel.com/home | 2026-08-21 |

Each is 1440 x 778, browser chrome removed, re-encoded at quality 82.

**Rights.** Every page, its copy, its artwork and its marks belong to its owner
(Google, OpenAI, Linear, Raycast, Vercel). Nothing here is licensed by this
repository, and the repository's own licence does not extend to these files.
They are included only so an agent reading this skill can SEE the compositions
the analysis measures, the same way a design review pins printouts to a wall.

**Rules of use, enforced by the skill.**

- References are vocabulary, never templates. A lock cites the PATTERN
  ("left-anchored spine with a product shelf"), never "make it look like this
  image" (`SKILL.md` § Visual evidence).
- Never reproduce a capture, or any part of one, inside a project you build.
  No traced artwork, no copied copy, no borrowed marks.
- Never ship these files, or a crop of one, as an asset of a delivered site.

Own, freely reusable schematics of the same compositions - zone diagrams with
no third-party artwork in them - are in `../plates/` and are CC0. Prefer those
when something needs to be displayed rather than studied.

If you own one of these pages and would rather the capture were not here, open
an issue on the repository and it will be removed.
